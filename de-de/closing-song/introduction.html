Hinweis

Der Closing Song-Server wird von Korvahet betrieben.

Closing Song

Willkommen auf Closing Song, einem langfristig laufenden 1.20.1-Forge-Mod-Survival-Server mit dem aktuellen Paket „Closing Songopen in new window“. Sowohl Premium- als auch Offline-Accounts betreten ihn direkt, ohne Whitelist-Antrag; wenn ein Paket ausgelutscht ist, wechseln wir einfach zum nächsten — Server und Community bleiben.

Hinweis

Obwohl auf dem Server keine Premium-Authentifizierung aktiviert ist, benötigen Nicht-Premium-Nutzer einen LittleSkin-Login, um dem Server beizutreten. Daher registrieren sich Nicht-Premium-Nutzer bitte zuerst bei LittleSkin und melden sich in einem Drittanbieter-Launcher mit ihrem LittleSkin-Konto an, bevor sie dem Server beitreten!

Hauptmerkmale

Langfristig, ohne Aufwand: keine Welten-Resets und keine häufigen Wipes; vor einem Paketwechsel kündigen wir es rechtzeitig in der Gruppe an und behalten ein Backup der alten Welt.

Premium und Offline willkommen: Premium-Accounts melden sich direkt an; Offline-Accounts kommen genauso rein — Freunde einladen hat keinerlei Hürde.

Original-Paket-Erlebnis, keine Eigenbastelei: Der Server läuft mit der originalen Mod-Liste des Pakets und fügt keine zusätzlichen Mods hinzu; ist eine Anpassung wirklich nötig, erklären wir sie zuerst in der Gruppe.

Klein, aber stabil: etwa 15 Spieler online, kein Gedränge; bei vollem Server nicht hereinzukommen ist normal — kurz warten oder in der Gruppe Bescheid sagen.
