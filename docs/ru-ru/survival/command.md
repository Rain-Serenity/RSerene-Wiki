# Список команд
| Команда                                                 | Описание                                                                    | Примечание                                                                                                                                                                        |
|---------------------------------------------------------|-----------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| /back                                                   | Вернуться на последнее сохранённое место                                    |                                                                                                                                                                                   |
| /balance                                                | Проверить свой баланс                                                       |                                                                                                                                                                                   |
| /baltop                                                 | Посмотреть топ баланса                                                      |                                                                                                                                                                                   |
| /co i                                                   | Включить(выключить) режим просмотра истории блоков                          |                                                                                                                                                                                   |
| /dback                                                  | Вернуться на место последней смерти                                         |                                                                                                                                                                                   |
| /gmp mailbox                                            | Открыть почтовый ящик; предметы, снятые с глобального рынка, хранятся здесь |                                                                                                                                                                                   |
| /gmp market gui                                         | Открыть глобальный рынок                                                    |                                                                                                                                                                                   |
| /gmp market help                                        | Просмотреть доступные команды глобального рынка                             |                                                                                                                                                                                   |
| /gmp market sell &lt;цена&gt; &lt;количество&gt;        | Выставить предмет из руки на глобальный рынок по указанной цене             |                                                                                                                                                                                   |
| /money                                                  | Проверить баланс                                                            |                                                                                                                                                                                   |
| /msg                                                    | Отправить личное сообщение игроку                                           |                                                                                                                                                                                   |
| /pay &lt;игрок&gt; &lt;сумма&gt;                        | Перевести деньги игроку                                                     | Комиссия 3%                                                                                                                                                                       |
| /ping                                                   | Проверить задержку                                                          |                                                                                                                                                                                   |
| /playtime                                               | Проверить общее время игры                                                  |                                                                                                                                                                                   |
| /playtimetop                                            | Посмотреть топ игроков по времени игры                                      |                                                                                                                                                                                   |
| /removehome &lt;название дома&gt;                       | Удалить дом                                                                 |                                                                                                                                                                                   |
| /res create &lt;название&gt;                            | Создать территорию                                                          | Сначала нужно выбрать две точки деревянной мотыгой                                                                                                                                |
| /res give &lt;название&gt; &lt;игрок&gt;                | Передать территорию игроку                                                  | Требуется подтверждение командой /res confirm                                                                                                                                     |
| /res help                                               | Получить помощь по плагину территорий                                       |                                                                                                                                                                                   |
| /res pset &lt;игрок&gt; &lt;право&gt; true/false/remove | Настроить личные права на территорию                                        | При выполнении внутри нужной территории название указывать не нужно; если использовать только /res set &lt;игрок&gt;, откроется GUI настроек прав этого игрока на этой территории |
| /res remove &lt;название&gt;                            | Удалить территорию                                                          | Требуется подтверждение командой /res confirm                                                                                                                                     |
| /res set &lt;право&gt; true/false/remove                | Настроить общие права территории                                            | При выполнении внутри нужной территории название указывать не нужно; если использовать только /res set, откроется GUI общих настроек прав территории                              |
| /rtp                                                    | Случайная телепортация                                                      | Радиус: 32000*32000                                                                                                                                                               |
| /sell gui                                               | Открыть меню продажи                                                        | Продаваемые предметы см. в "Базовых настройках"                                                                                                                                   |
| /spawn                                                  | Телепортироваться в главный город                                           |                                                                                                                                                                                   |
| /tpa                                                    | Запросить телепортацию к другому игроку                                     |                                                                                                                                                                                   |
| /tpahere                                                | Запросить телепортацию другого игрока к вам                                 |                                                                                                                                                                                   |
| /tpsbar                                                 | Включить(выключить) отображение TPS, MSPT и т.д. в вашем регионе            |                                                                                                                                                                                   |
| /worth                                                  | Проверить стоимость продажи предмета в руке                                 |                                                                                                                                                                                   |
| /worthlist                                              | Посмотреть стоимость всех продаваемых предметов                             |                                                                                                                                                                                   |
