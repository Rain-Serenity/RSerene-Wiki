# Список команд
| Команда                                     | Описание                                                                    | Примечание                                                                                                                                                                  |
|---------------------------------------------|-----------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| /back                                       | Вернуться на последнее сохранённое место                                    |                                                                                                                                                                             |
| /balance                                    | Проверить свой баланс                                                       |                                                                                                                                                                             |
| /baltop                                     | Посмотреть топ баланса                                                      |                                                                                                                                                                             |
| /co i                                       | Включить(выключить) режим просмотра истории блоков                          |                                                                                                                                                                             |
| /dback                                      | Вернуться на место последней смерти                                         |                                                                                                                                                                             |
| /gmp mailbox                                | Открыть почтовый ящик; предметы, снятые с глобального рынка, хранятся здесь |                                                                                                                                                                             |
| /gmp market gui                             | Открыть глобальный рынок                                                    |                                                                                                                                                                             |
| /gmp market help                            | Просмотреть доступные команды глобального рынка                             |                                                                                                                                                                             |
| /gmp market sell <цена> <количество>        | Выставить предмет из руки на глобальный рынок по указанной цене             |                                                                                                                                                                               |
| /home                                       | Телепорт к своему дому                                                      |                                                                                                                                                                             |
| /homes                                      | Список всех своих домов                                                     |                                                                                                                                                                             |
| /money                                      | Проверить баланс                                                            |                                                                                                                                                                             |
| /msg                                        | Отправить личное сообщение игроку                                           |                                                                                                                                                                             |
| /pay <игрок> <сумма>                        | Перевести деньги игроку                                                     | Комиссия 3%                                                                                                                                                                 |
| /ping                                       | Проверить задержку                                                          |                                                                                                                                                                             |
| /playtime                                   | Проверить общее время игры                                                  |                                                                                                                                                                             |
| /playtimetop                                | Посмотреть топ игроков по времени игры                                      |                                                                                                                                                                             |
| /removehome <название дома>                 | Удалить дом                                                                 |                                                                                                                                                                             |
| /res create <название>                      | Создать территорию                                                          | Сначала нужно выбрать две точки деревянной мотыгой                                                                                                                          |
| /res give <название> <игрок>                | Передать территорию игроку                                                  | Требуется подтверждение командой /res confirm                                                                                                                               |
| /res help                                   | Получить помощь по плагину территорий                                       |                                                                                                                                                                             |
| /res pset <игрок> <право> true/false/remove | Настроить личные права на территорию                                        | При выполнении внутри нужной территории название указывать не нужно; если использовать только /res set <игрок>, откроется GUI настроек прав этого игрока на этой территории |
| /res remove <название>                      | Удалить территорию                                                          | Требуется подтверждение командой /res confirm                                                                                                                               |
| /res set <право> true/false/remove          | Настроить общие права территории                                            | При выполнении внутри нужной территории название указывать не нужно; если использовать только /res set, откроется GUI общих настроек прав территории                        |
| /rtp                                        | Случайная телепортация                                                      | Радиус: 32000*32000                                                                                                                                                         |
| /sell gui                                   | Открыть меню продажи                                                        | Продаваемые предметы см. в «Основных настройках»                                                                                                                            |
| /sethome <название дома>                    | Поставить дом                                                               | До 8 домов                                                                                                                                                                  |
| /spawn                                      | Телепортироваться в главный город                                           |                                                                                                                                                                             |
| /tpa                                        | Запросить телепортацию к другому игроку                                     |                                                                                                                                                                             |
| /tpahere                                    | Запросить телепортацию другого игрока к вам                                 |                                                                                                                                                                             |
| /tpsbar                                     | Включить(выключить) отображение TPS, MSPT и т.д. в вашем регионе            |                                                                                                                                                                             |
| /worth                                      | Проверить стоимость продажи предмета в руке                                 |                                                                                                                                                                             |
| /worthlist                                  | Посмотреть стоимость всех продаваемых предметов                             |                                                                                                                                                                             |
