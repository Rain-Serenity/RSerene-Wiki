# Список команд
::: tip Подсказка
Сервер работает по оригинальному сбору без собственных команд; ниже — ванильные команды, доступные в игре.
:::
| Команда     | Описание                                 | Примечание                     |
|-------------|------------------------------------------|--------------------------------|
| /seed       | Посмотреть сид текущего мира             |                                |
| /spawnpoint | Задать личную точку появления            |                                |
| /locate     | Найти ближайший биом или структуру       | Требуются права администратора |
| /trigger    | Запустить заранее заданное событие табло | Настраивается администратором  |
