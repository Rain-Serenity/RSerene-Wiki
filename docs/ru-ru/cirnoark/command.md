# Список команд
::: tip Подсказка
Сервер Perfect Arithmetic Workshop (CirnoArk) управляется игроком Korvahet.
:::

| Команда                              | Функция                                                                     | Примечание                                                    |
|--------------------------------------|-----------------------------------------------------------------------------|---------------------------------------------------------------|
| /back                                | Вернуться на предыдущую сохранённую точку                                   |                                                               |
| /balance                             | Посмотреть свой баланс                                                      |                                                               |
| /baltop                              | Таблица лидеров по балансу                                                  |                                                               |
| /co i                                | Включить (выключить) режим проверки блоков                                  |                                                               |
| /dback                               | Вернуться на место последней смерти                                         |                                                               |
| /gmp mailbox                         | Открыть почтовый ящик; предметы, снятые с глобального рынка, хранятся здесь |                                                               |
| /gmp market gui                      | Открыть глобальный рынок                                                    |                                                               |
| /gmp market help                     | Просмотреть доступные команды глобального рынка                             |                                                               |
| /gmp market sell <цена> <количество> | Выставить предмет из руки на глобальный рынок по указанной цене             |                                                               |
| /home                                | Телепорт к своему дому                                                      |                                                               |
| /homes                               | Список всех своих домов                                                     |                                                               |
| /money                               | Посмотреть свой баланс                                                      |                                                               |
| /msg                                 | Отправить личное сообщение игроку                                           |                                                               |
| /pay <игрок> <сумма>                 | Перевести деньги игроку                                                     | Комиссия 3%                                                   |
| /ping                                | Проверить свой пинг                                                         |                                                               |
| /playtime                            | Посмотреть время, проведённое на сервере                                    |                                                               |
| /playtimetop                         | Таблица лидеров по времени на сервере                                       |                                                               |
| /removehome <название>               | Удалить дом                                                                 |                                                               |
| /res create <название>               | Создать участок                                                             | Сначала выделите два угла деревянной мотыгой                  |
| /res info <название>                 | Показать сведения об участке                                                |                                                               |
| /res list                            | Список всех своих участков                                                  |                                                               |
| /res padd <игрок> <флаг>             | Выдать игроку права на участок                                              | Только строительство, разрушение, контейнеры и взаимодействие |
| /res remove <название>               | Удалить участок                                                             |                                                               |
| /res set <флаг> true/false           | Задать общий флаг участка                                                   | Выполняйте внутри нужного участка                             |
| /res sethome <название>              | Поставить точку телепорта на участке                                        |                                                               |
| /rtp                                 | Случайный телепорт                                                          | От 3200 до 32000 блоков, откат 10 минут                       |
| /sell gui                            | Продать предметы из инвентаря                                               | Список продаваемого — в разделе «Основные настройки»          |
| /sf                                  | Открыть меню Slimefun                                                       | Руководство, поиск рецептов и прогресс исследований           |
| /sf guide                            | Открыть стартовое руководство Slimefun                                      | При первом заходе вы получаете его автоматически              |
| /sfcalc calc <предмет> [количество]  | Посчитать материалы для предмета                                            | Короткая форма: /sfc calc <предмет> [количество]              |
| /sethome <название>                  | Поставить дом                                                               | До 8 домов                                                    |
| /spawn                               | Телепорт в главный город                                                    |                                                               |
| /tpa <игрок>                         | Запросить телепорт к игроку                                                 | Запрос живёт 60 секунд                                        |
| /tpahere <игрок>                     | Вызвать игрока к себе                                                       |                                                               |
| /worth                               | Узнать стоимость предмета в руке                                            |                                                               |
| /worthlist                           | Посмотреть стоимость всех продаваемых предметов                             |                                                               |

::: tip Подсказка
В чате `[inv]`, `[ender]` и `[item]` показывают ваш инвентарь, эндер-сундук и предмет в руке; `ник` упоминает игрока.
:::
