# Список команд
::: tip Подсказка
Сервер Perfect Arithmetic Workshop (CirnoArk) управляется игроком Chosen_1st.
:::

## Команды, доступные всем игрокам

Эти команды открыты для всех и работают без дополнительных прав.

### Телепорты и перемещение
| Команда | Описание |
|---|---|
| `/back` | Вернуться на предыдущую позицию |
| `/dback` | Вернуться на место последней смерти |
| `/home` | Телепорт к своему дому |
| `/homes` | Показать список всех своих домов |
| `/sethome &lt;название&gt;` | Поставить дом на текущей точке (по умолчанию Home) |
| `/removehome &lt;название&gt;` | Удалить дом |
| `/spawn` | Вернуться на спавн |
| `/tpa &lt;игрок&gt;` | Запросить телепорт к игроку (запрос живёт 60 секунд, отсчёт 3 секунды) |
| `/tpahere &lt;игрок&gt;` | Вызвать игрока к себе |
| `/tpaccept` | Принять запрос на телепорт |
| `/tpdeny` | Отклонить запрос на телепорт |
| `/rtp` | Случайный телепорт (откат 10 минут, точка в радиусе 3200 ~ 32000 блоков в главном мире) |

### Деньги и магазин
| Команда | Описание |
|---|---|
| `/balance` | Показать свой баланс |
| `/money` | Показать свой баланс |
| `/pay &lt;игрок&gt; &lt;сумма&gt;` | Перевести деньги другому игроку (комиссия 3%) |
| `/baltop` | Таблица лидеров по балансу |
| `/sell` | Продать предметы из инвентаря (по таблице цен) |
| `/worth` | Узнать стоимость предмета в руке |
| `/worthlist` | Открыть полную таблицу цен на предметы |

### Чат и информация
| Команда | Описание |
|---|---|
| `/msg &lt;игрок&gt; &lt;сообщение&gt;` | Личное сообщение другому игроку |
| `/ping` | Показать свой пинг |
| `/playtime` | Показать время, проведённое на сервере |
| `/playtimetop` | Таблица лидеров по времени на сервере |
| `/shout &lt;сообщение&gt;` | Крик на весь сервер (откат 3 секунды) |

**Полезно в чате:**
- `@ник` — упомянуть игрока (откат 30 секунд).
- `@all` — обратиться ко всем (откат 5 минут, нужны дополнительные права).
- `[inv]` — показать свой инвентарь прямо в чате.
- `[ender]` — показать свой эндер-сундук прямо в чате.
- `[item]` — показать предмет в руке прямо в чате.

### Slimefun и геймплей
| Команда | Описание |
|---|---|
| `/sf` | Главная команда Slimefun: руководство, поиск рецептов, прогресс исследований |
| `/sf guide` | Открыть стартовое руководство (при первом заходе вы получаете его автоматически) |
| `/sfcalc calc &lt;предмет&gt; [количество]` | Калькулятор рецептов: показывает, какие материалы нужны для предмета (или для N штук) |
| `/sfc calc &lt;предмет&gt; [количество]` | То же самое, короткая форма `/sfcalc` |

::: tip Подсказка
`/sfcalc` только показывает рецепт и ничего не тратит — это самый быстрый способ подготовить производственную линию.
:::

## Команды, которые пока недоступны

Эти команды на сервере **существуют, но игрокам не выданы** — не удивляйтесь, если ими пользуются другие:

| Команда | Описание |
|---|---|
| `/tp` | Прямой телепорт, игрокам не открыт (используйте `/tpa`) |
| `/warp`, `/setwarp` | Система варпов: точек пока нет, доступ не открыт |
| `/kit` | Наборы: сейчас ни одного набора не настроено |
| `/heal`, `/feed` | Лечение и насыщение, не открыты |
| `/fly`, `/effect`, `/enchant`, `/give`, `/gamerule` | Творческие и читерские команды, не открыты |
| `/nick` | Смена ника, не открыта |
| `/rankup` | Система рангов, сейчас отключена |
| `/tpaccept`, `/tpdeny` | Права выданы, но псевдонимы отключены — принимайте и отклоняйте прямо в `/tpa` |

## Про права доступа
- Правами управляет **LuckPerms**. Сейчас на сервере есть только группа `default`: 30 командных прав `cmi.command.*`, а также проверка блоков (`coreprotect.inspect`) и запрос состояния сервера.
- **`/residence.group.Default` и `/residence.group.Event` отвечают за два разных лимита участков**: у группы по умолчанию 8 участков, у группы событий — 12.
- Флаги участка (можно ли строить, ломать, открывать сундуки, включать PvP, взрывы и так далее) задаёт **сам владелец участка** — это отдельная от командных прав система.
- Забаненным и заглушенным административные команды недоступны.

## Коротко по частым вопросам
- **Команда не срабатывает?** Сначала проверьте написание; для `/tpa` игрок должен быть в сети, а запрос живёт 60 секунд.
- **Не могу взять или использовать предмет?** Часть предметов защищена флагами участка (контейнеры, разрушение, взаимодействие) — попросите владельца участка выдать права.
- **Хочу узнать, как делается предмет?** `/sfcalc calc &lt;предмет&gt;` — куда быстрее, чем листать рецепты.
