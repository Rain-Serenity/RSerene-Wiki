# 服务器管理条例

## I. 服务器性质与玩家守则

### 1. 服务器性质
- **公益属性**：雨润服务器是一个 Minecraft Java 版公益服务器。
- **赞助原则**：本服务器不包含任何付费项目，但接受玩家自愿且无条件的捐助。
- **现实交易免责**：本服务器不限制玩家在现实世界中对游戏内物品进行有偿交易，但对玩家之间引起的任何现实经济纠纷不承担任何法律与连带责任。

### 2. 玩家基本守则
- **年龄建议**：根据各地区官方分级，本游戏在欧洲 PEGI 体系下适合 **7 岁及以上**，在北美 ESRB 体系下适合 **10 岁及以上**，在中国大陆（CADPA）适龄提示为 **8 周岁及以上**（iOS 商店分级为 9+）。如果您未满相应年龄，建议在监护人陪同下游玩。
- **玩家公约**：请尊重并友善地对待每一位玩家。
- **账号安全与责任**：玩家需妥善保管自己的游戏账号及密码。因账号借出、共享、出售或密码泄露导致的物品丢失、封禁等后果，由玩家自行承担。

### 3. 争议处理
- 在游玩过程中如遇问题、矛盾或争端，请保持冷静和理性，必要时可联系管理员介入协调。

## II. 服务边界与免责声明

### 1. 服务边界
- 本服务器为公益服务器，管理团队**仅负责**服务器的基础运行、规则维护及违规行为的处理，**不提供**“保姆式”个性化服务。
- 管理团队原则上不承担以下事项的责任：
  1. **建筑与地形**：不协助玩家移动、迁移、复制、修复、重建或拆除建筑群；不协助破除基岩、清理地形、制造或提供空置域。
  2. **事故与损失**：不因玩家机器故障、红石装置失灵、爆炸物、苦力怕、实验失败或误操作等造成的物品、建筑、地形损失提供理赔、回档、补偿或恢复。
  3. **玩家间纠纷**：不介入玩家之间因自愿合作、借用、赠送、交易或共用设施等产生的游戏内纠纷；但涉及作弊、偷盗、恶意破坏、恶意 PvP 等违规行为的，仍按规则处理。

### 2. 风险自担与违规举报
- 玩家应自行评估并承担游戏内建造、红石、爆炸物及实验操作的风险。
- 若损失系其他玩家违规造成，请保留证据并通过 QQ 群等渠道举报，管理团队将依据规则处理。

### 3. 管理团队援助说明
- 管理团队是否提供额外协助由管理团队自行决定，任何协助均不构成义务、承诺或先例。
- 请勿因未获上述非义务协助而骚扰、辱骂或刷屏管理团队，否则将依据本条例中“不当言论”“恶意刷屏”等规定处理。

## III. 违规行为及处理

::: warning 违规处理提示
对于以下违规行为，管理团队将视**情节轻重**及**造成的实际影响**，给予警告、临时封禁、永久封禁或移出社区群聊等处罚。若违规行为涉及多个账号，将视同主号违规。
:::

### 1. 社区行为规范
- **不当言论**：发表歧视、攻击性或严重不当的言论（详见第 IV 节）。
- **不良内容**：发布色情、令人反感或过于暴力的内容。
- **恶意刷屏**：发送垃圾信息或恶意刷屏。
- **冒充与广告**：冒充他人、发布未经许可的广告或进行其他不当行为。

### 2. 游戏内行为规范
- **作弊行为**
  - 使用作弊客户端、外挂或违规模组。
  - 恶意利用服务器或游戏漏洞。
- **恶意破坏**
  - 未经许可破坏或篡改他人的建筑与劳动成果。
  - 未经许可拿取或偷盗他人容器内的物品。
  - 恶意 PvP（在非允许区域或未经双方同意强行击杀玩家）。
- **滥用机制**
  - 滥用插件功能（如利用领地插件圈占他人建筑）。
  - 故意重复发送相同指令，或使用宏/脚本造成指令刷屏。
- **危害服务器运行**
  - **制造卡顿**：恶意建造高频红石、大量堆积实体，或利用其他机制故意造成服务器严重卡顿。
  - **拒不整改**：经管理员明确警告后，仍拒不清除或整改导致卡顿的设施。
  - **屡教不改**：因卡服问题经管理员警告并整改后，再次出现同类行为的，将从重处罚，**情节严重的直接适用第 IV 节零容忍原则**。
- **违规建筑**
  - 建造任何不雅、违规或令人反感的建筑。
- **规避处罚**
  - 创建或使用小号（备用账号）逃避封禁、刷取物资或进行违规行为。

## IV. 零容忍原则

::: danger 特别声明
以下违规行为一经查实，将**直接予以永久封禁并移出社区群聊**，且**不接受任何形式的申诉**。
:::

### 1. 言论与隐私底线

| 违规项目        | 违规行为说明                           |
|:------------|:---------------------------------|
| **种族与性别歧视** | 包含种族、性别歧视，或针对特定性别的攻击言论。          |
| **性少数群体歧视** | 针对同性恋、跨性别等 LGBTQ+ 群体的歧视、侮辱或仇恨言论。 |
| **特殊群体侮辱**  | 针对残疾人等群体的侮辱、嘲讽或仇恨言论。             |
| **其他仇恨言论**  | 未在上文列出的其他形式仇恨言论。                 |
| **隐私泄露**    | 未经允许泄露、传播或倒卖他人在现实世界中的个人隐私或真实信息。  |
| **恶劣人身攻击**  | 恶劣的个人人身攻击或带有持续骚扰性质的毒性言论。         |

### 2. 重大恶性违规

| 违规项目          | 违规行为说明                                          |
|:--------------|:------------------------------------------------|
| **严重破坏社区环境**  | 多次发表不当言论、不良内容或恶意刷屏，对社区氛围造成严重破坏。                 |
| **严重破坏游戏体验**  | 情节恶劣的作弊、恶意破坏、滥用机制或违规建筑，严重影响服务器正常运营。             |
| **威胁服务器安全**   | 对服务器进行网络攻击（如 DDoS）、恶意探测漏洞、利用底层漏洞谋利等危害服务器安全的行为。  |
| **恶意导致服务器瘫痪** | 利用超大实体炸弹、恶意区块加载漏洞或极端红石高频等手段，直接导致服务器崩溃、死锁或大面积回档。 |
| **现实违法关联**    | 在游戏内或社区群聊中，进行或宣扬现实世界中的违法犯罪活动。                   |

## V. 封禁申诉与附则

### 1. 申诉流程
- 若您对非“**零容忍原则**”的封禁处理结果存在异议，可在接到封禁通知后的 **7 天内**，通过服务器 QQ 群等渠道向管理员提交申诉，申请减轻处罚或解除封禁。逾期视为接受处罚结果。
- 违反本条例第 IV 节“零容忍原则”中任意一条的封禁，将不再受理申诉。

### 2. 附则
- **管理团队声明**：管理团队成员均为义务参与服务器管理的玩家，请尊重管理员的劳动付出。如对管理员处理结果有异议，请通过正当渠道（如申诉）解决，严禁在群内或游戏内对管理员进行人身攻击、辱骂或刷屏。
- **最终解释权**：本管理团队保留对服务器管理条例的最终解释权及修订权。
- **服规修订**：本管理条例将根据服务器实际运营情况不定期进行修订。新规发布后即时生效，如有冲突，以最新版本为准。
