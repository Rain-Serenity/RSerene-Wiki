# Command List
::: tip Tips
This server runs the modpack as-is with no custom server commands; the following are the vanilla commands available in game.
:::
| Command     | Function                                 | Remarks                   |
|-------------|------------------------------------------|---------------------------|
| /seed       | View the seed of the current world       |                           |
| /spawnpoint | Set your personal spawn point            |                           |
| /locate     | Find the nearest biome or structure      | Requires admin permission |
| /trigger    | Trigger a preconfigured scoreboard event | Set up by an admin        |
