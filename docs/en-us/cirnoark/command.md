# Command List
::: tip Tips
The CirnoArk server is operated by Korvahet.
:::

| Command | Function | Notes |
|---|---|---|
| /back | Return to your previous saved location |  |
| /balance | Check your balance |  |
| /baltop | View the balance leaderboard |  |
| /co i | Toggle the block-record lookup mode |  |
| /dback | Return to your last death location |  |
| /home | Teleport to your home |  |
| /homes | List all of your homes |  |
| /msg | Send a private message to another player |  |
| /money | Check your balance |  |
| /pay &lt;player&gt; &lt;amount&gt; | Send money to another player | 3% fee |
| /ping | Check your latency |  |
| /playtime | Check your time on the server |  |
| /playtimetop | View the playtime leaderboard |  |
| /removehome &lt;name&gt; | Delete a home |  |
| /res create &lt;claim name&gt; | Create a claim | Select two corners with a wooden hoe first |
| /res info &lt;claim name&gt; | Show claim information |  |
| /res list | List all of your claims |  |
| /res padd &lt;player&gt; &lt;flag&gt; | Grant a player access to your claim | Building, breaking, container and interaction flags only |
| /res remove &lt;claim name&gt; | Delete a claim |  |
| /res set &lt;flag&gt; true/false | Set a global claim flag | Run it inside the claim you want to change |
| /res sethome &lt;claim name&gt; | Set a teleport point inside a claim |  |
| /rtp | Random teleport | 3200 ~ 32000 blocks, 10-minute cooldown |
| /sell | Sell the items in your inventory | See "Settings" for the sellable items |
| /sf | Open the Slimefun menu | Guide, recipe lookup and research progress |
| /sf guide | Open the Slimefun starter guide | You receive one automatically on your first join |
| /sfcalc calc &lt;item&gt; [amount] | Work out the materials for an item | Short form: /sfc calc &lt;item&gt; [amount] |
| /sethome &lt;name&gt; | Set a home | Up to 8 homes |
| /shout &lt;message&gt; | Shout to the whole server | 3-second cooldown |
| /spawn | Teleport to the main city |  |
| /status | Show the server status |  |
| /tpa &lt;player&gt; | Request a teleport to another player | The request expires after 60 seconds |
| /tpahere &lt;player&gt; | Ask another player to teleport to you |  |
| /worth | Check the sell value of the item in your hand |  |
| /worthlist | Look up the value of every sellable item |  |

::: tip Tips
In chat, `[inv]`, `[ender]` and `[item]` instantly show your inventory, your ender chest and the item in your hand; `@name` mentions a player.
:::
