# 指令列表
::: tip 提示
本服务器按整合包原版运行，未添加自定义服务器指令；下列为游戏内可用的原版指令。
:::
| 指令名称        | 功能              | 备注        |
|-------------|-----------------|-----------|
| /seed       | 查看当前世界的种子       |           |
| /spawnpoint | 设置个人出生点         |           |
| /locate     | 查找最近的生物群系或结构    | 需要管理员权限   |
| /trigger    | 触发管理员预先设定的记分板事件 | 由管理员设置后使用 |
