## 서버 기본 구성
- **본 서버는 1.20.1 Forge 모드 서버이며, 로더 버전은 Forge 47.3.22으로 팩과 동일합니다.**
- **현재 팩: [Closing Song (V1.6.7.1)](https://www.mcmod.cn/modpack/1133.html).**
- **서버는 팩 원본의 mods 목록 그대로 운영되며 추가 모드를 넣지 않습니다. 꼭 조정이 필요한 경우 먼저 그룹에서 설명합니다.**

## 팩과 버전
- **게임 버전: 1.20.1**
- **로더: Forge 47.3.22**
- **Java 환경: Java 17**
- **팩은 QQ 그룹 902620497의 그룹 파일 또는 [공식 배포 페이지](https://www.mcmod.cn/modpack/1133.html)에서 다운로드하고, 원본 팩을 사용하며 모드를 직접 추가·삭제하지 마세요.**

## 업데이트와 공지
- 현재: **Closing Song** 팩이 운영 중입니다.
- 팩 변경 계획: 미정, 그룹에서 공지합니다.

## 저작권과 면책 고지
- 본 서버가 사용하는 팩(Closing Song 등)은 **인터넷에서 수집한 것으로 본 서버의 오리지널이 아니며**, 관련 저작권은 원저자 및 배포자에게 있습니다.
- 본 서버는 **플레이어에게 어떠한 비용도 징수하지 않으며**(기부는 전적으로 자발적) 팩을 어떤 형태로도 판매하거나 유료 배포하지 않습니다.
- 팩은 본 서버 플레이어의 정상적인 플레이를 위해서만 사용됩니다. 원저자 또는 배포자가 배포를 원하지 않으면 연락해 주세요. 즉시 관련 파일을 내리고 삭제하겠습니다.
- 원작자 지원 권장: [공식 배포 페이지](https://www.mcmod.cn/modpack/1133.html)에서 다운로드하고 작가 소식을 팔로우하세요.
