# 자주 묻는 질문

## I. 로그인과 참여 관련
### Q1：정품 계정이 필요한가요?
A：필요하지 않습니다. 정품과 오프라인 계정 모두 바로 입장할 수 있으며 화이트리스트 신청은 없습니다.

### Q2：팩은 어디서 다운로드하나요?
A：QQ 그룹 902620497의 **그룹 파일**에서 다운로드하세요. 원본 팩을 사용하고 모드를 직접 추가·삭제하지 마세요. 인터넷에서 원작자의 배포 페이지를 검색해 직접 받을 수도 있습니다.

### Q3：서버에 참여하는 방법은?
A：1. QQ 그룹 902620497에 가입하고 **그룹 파일**에서 "Closing Song" 팩을 다운로드;<br>
2. PCL, HMCL 등 런처에서 직접 "팩 가져오기"를 하고, 모드를 직접 재설치하거나 추가·삭제하지 않기;<br>
3. 실행 후 버전이 1.20.1-Forge이고 Java 17을 사용하는지 확인;<br>
4. 멀티플레이 → 서버 추가, 주소는 `CLSO.RSerene.com`;<br>
5. 첫 입장 시 관리자에게서 초보자 물자를 받을 수 있습니다. 자세한 내용은 그룹 공지를 참고하세요.

### Q4：왜 연결이 안 되거나 계속 재연결되나요?
A：먼저 버전이 1.20.1-Forge이고 Java 17을 사용하며 모드가 팩과 일치하는지 확인하세요. 주소는 `CLSO.RSerene.com`입니다. 그래도 연결이 안 되면 그룹에 문의하세요. 주소가 변경되었을 수 있습니다.

### Q5：돈이 드나요?
A：들지 않습니다. 플레이는 무료입니다(기부는 전적으로 자발적이며 강제가 아닙니다).

## II. 서버 메커니즘과 규칙
### Q1：서버는 몇 명까지 지원하나요?
A：동시 접속 약 15명입니다. 만석 시 입장이 안 되므로 잠시 기다리거나 그룹에 문의하세요.

### Q2：월드가 삭제되나요?
A：삭제되지 않습니다. 팩을 교체할 때 기존 월드를 먼저 백업한 후 교체합니다.

### Q3：팩은 언제 교체되나요?
A：현재 팩을 충분히 플레이한 후 교체합니다. 교체 전에 그룹에서 투표·공지를 진행합니다.

### Q4：렉이나 연결 끊김이 발생하면 어떻게 하나요?
A：먼저 그룹 공지에 재시작 일정이 없는지 확인하세요. 여러 사람이 동시에 끊긴다면 보통은 서버 재시작이나 네트워크 변동입니다. 잠시 후 다시 접속하세요.

### Q5：서버에 어떤 규칙이 있나요?
A：핵, 투시, 비행, 자리비움, 스크립트 아이템 생성 금지; 악의적 PvP, 기지 습격, 타인 건물 파괴, 도배, 욕설 금지; 바닐라 레드스톤 장치와 몹 농장은 사용 가능하지만 의도적으로 서버를 렉걸게 하거나 청크 로더를 악용하는 것은 금지합니다. 구체적인 조항은 그룹 공지에 따릅니다.

## III. 저작권과 커뮤니티
### Q1：팩을 임의로 배포하거나 판매할 수 있나요?
A：할 수 없습니다. 본 서버는 플레이어에게 어떠한 비용도 징수하지 않으며 팩을 어떤 형태로도 판매하거나 유료 배포하지 않습니다. 팩은 본 서버 플레이어의 정상적인 플레이를 위해서만 사용됩니다.

### Q2：문제는 어디에 신고하나요?
A：게임 내에서 온라인 관리자에게 문의하거나 공식 QQ 그룹 902620497에 가입하여 그룹 내 @관리자 또는 @Chosen-1st에게 연락하세요.
