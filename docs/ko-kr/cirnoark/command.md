# 명령어 목록
::: tip 팁
CirnoArk 서버는 Korvahet가 운영합니다.
:::

| 명령어 | 기능 | 비고 |
|---|---|---|
| /back | 직전 저장 지점으로 돌아갑니다 |  |
| /balance | 내 잔액을 확인합니다 |  |
| /baltop | 잔액 순위표를 봅니다 |  |
| /co i | 블록 기록 조회 모드를 켜거나 끕니다 |  |
| /dback | 직전 사망 지점으로 돌아갑니다 |  |
| /home | 내 집으로 텔레포트합니다 |  |
| /homes | 내 모든 집을 확인합니다 |  |
| /msg | 다른 플레이어에게 개인 메시지를 보냅니다 |  |
| /money | 내 잔액을 확인합니다 |  |
| /pay <플레이어> <금액> | 다른 플레이어에게 송금합니다 | 수수료 3% |
| /ping | 내 지연 시간을 확인합니다 |  |
| /playtime | 온라인 시간을 확인합니다 |  |
| /playtimetop | 온라인 시간 순위표를 봅니다 |  |
| /removehome <집 이름> | 집을 삭제합니다 |  |
| /res create <영토 이름> | 영토를 만듭니다 | 먼저 나무 호 hoe 로 두 지점을 선택하세요 |
| /res info <영토 이름> | 영토 정보를 봅니다 |  |
| /res list | 내 모든 영토를 확인합니다 |  |
| /res padd <플레이어> <권한> | 플레이어에게 영토 권한을 부여합니다 | 건설·파괴·컨테이너·상호작용만 가능합니다 |
| /res remove <영토 이름> | 영토를 삭제합니다 |  |
| /res set <권한> true/false | 영토 전체 권한을 설정합니다 | 조정할 영토 안에서 실행하세요 |
| /res sethome <영토 이름> | 영토 안의 텔레포트 지점을 설정합니다 |  |
| /rtp | 무작위 텔레포트 | 범위 3200 ~ 32000, 쿨다운 10분 |
| /sell | 인벤토리 아이템을 판매합니다 | 판매 가능 아이템은「기본 설정」참고 |
| /sf | 슬라임 기술 메뉴를 엽니다 | 가이드·레시피 검색·연구 진행도 |
| /sf guide | 슬라임 기술 초보 가이드를 엽니다 | 첫 접속 시 자동으로 받습니다 |
| /sfcalc calc <아이템> [수량] | 아이템에 필요한 재료를 계산합니다 | /sfc calc <아이템> [수량] 도 사용 가능 |
| /sethome <집 이름> | 집을 설정합니다 | 최대 8개까지 |
| /shout <내용> | 전체 서버에 외칩니다 | 쿨다운 3초 |
| /spawn | 주도시로 텔레포트합니다 |  |
| /status | 서버 상태를 봅니다 |  |
| /tpa <플레이어> | 다른 플레이어에게 텔레포트를 요청합니다 | 요청은 60초 뒤에 만료됩니다 |
| /tpahere <플레이어> | 다른 플레이어를 내 쪽으로 부릅니다 |  |
| /worth | 손에 든 아이템의 판매 가치를 확인합니다 |  |
| /worthlist | 판매 가능한 모든 아이템의 가치를 확인합니다 |  |

::: tip 팁
채팅에서 `[inv]`, `[ender]`, `[item]`을 입력하면 인벤토리·엔더 상자·손에 든 아이템이 바로 표시됩니다. `@이름`으로 플레이어를 부를 수 있습니다.
:::
