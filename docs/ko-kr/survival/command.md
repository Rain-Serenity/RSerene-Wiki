# 명령어 목록
| 명령어                                       | 기능                                 | 비고                                                                                       |
|-------------------------------------------|------------------------------------|------------------------------------------------------------------------------------------|
| /back                                     | 마지막 저장 위치로 돌아가기                    |                                                                                          |
| /balance                                  | 잔액 확인                              |                                                                                          |
| /baltop                                   | 잔액 순위 보기                           |                                                                                          |
| /co i                                     | 블록 기록 조회 모드 켜기(끄기)                 |                                                                                          |
| /dback                                    | 마지막 사망 위치로 돌아가기                    |                                                                                          |
| /gmp mailbox                              | 우편함 열기; 글로벌 마켓에서 내린 아이템이 보관됨       |                                                                                          |
| /gmp market gui                           | 글로벌 마켓 열기                          |                                                                                          |
| /gmp market help                          | 글로벌 마켓에서 사용 가능한 명령어 보기             |                                                                                          |
| /gmp market sell <가격> <수량>                | 손에 든 아이템을 지정 가격으로 글로벌 마켓에 등록       |                                                                                          |
| /money                                    | 잔액 확인                              |                                                                                          |
| /msg                                      | 플레이어에게 귓속말 보내기                     |                                                                                          |
| /pay <플레이어명> <금액>                         | 플레이어에게 송금                          | 수수료 3%                                                                                   |
| /ping                                     | 지연 시간 확인                           |                                                                                          |
| /playtime                                 | 플레이 시간 확인                          |                                                                                          |
| /playtimetop                              | 서버 플레이 시간 순위 보기                    |                                                                                          |
| /removehome <집 이름>                        | 집 삭제                               |                                                                                          |
| /res create <영토 이름>                       | 영토 생성                              | 먼저 나무 괭이로 두 지점을 선택해야 함                                                                   |
| /res give <영토 이름> <플레이어명>                 | 영토를 플레이어에게 양도                      | /res confirm으로 확인 필요                                                                     |
| /res help                                 | 영토 플러그인 도움말 보기                     |                                                                                          |
| /res pset <플레이어명> <권한명> true/false/remove | 영토 개인 권한 설정                        | 변경할 영토 안에서 실행하면 영토 이름을 지정할 필요 없음. /res set <플레이어명>만 사용하면 해당 플레이어의 이 영토 권한 설정 GUI를 열 수 있음 |
| /res remove <영토 이름>                       | 영토 삭제                              | /res confirm으로 확인 필요                                                                     |
| /res set <권한명> true/false/remove          | 영토 전체 권한 설정                        | 변경할 영토 안에서 실행하면 영토 이름을 지정할 필요 없음. /res set만 사용하면 영토 전체 권한 설정 GUI를 열 수 있음                 |
| /rtp                                      | 무작위 텔레포트                           | 범위 32000*32000                                                                           |
| /sell gui                                 | 판매 메뉴 열기                           | 판매 가능 아이템은 "기본 설정" 참조                                                                    |
| /spawn                                    | 스폰으로 텔레포트                          |                                                                                          |
| /tpa                                      | 다른 플레이어에게 텔레포트 요청                  |                                                                                          |
| /tpahere                                  | 다른 플레이어가 자신에게 텔레포트하도록 요청           |                                                                                          |
| /tpsbar                                   | 자신이 있는 지역의 TPS, MSPT 등의 표시줄 켜기(끄기) |                                                                                          |
| /worth                                    | 손에 든 아이템의 판매 가치 확인                 |                                                                                          |
| /worthlist                                | 판매 가능한 모든 아이템의 가치 보기               |                                                                                          |
