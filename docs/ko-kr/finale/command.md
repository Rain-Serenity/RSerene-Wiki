# 명령어 목록
::: tip 팁
본 서버는 팩 원본으로 운영되며 자체 서버 명령어를 추가하지 않습니다. 아래는 게임 내에서 사용할 수 있는 바닐라 명령어입니다.
:::
| 명령어         | 기능                        | 비고          |
|-------------|---------------------------|-------------|
| /seed       | 현재 월드의 시드를 확인한다           |             |
| /spawnpoint | 개인 리스폰 지점을 설정한다           |             |
| /locate     | 가장 가까운 바이옴이나 구조물을 찾는다     | 관리자 권한 필요   |
| /trigger    | 관리자가 미리 설정한 점수판 이벤트를 실행한다 | 관리자 설정 후 사용 |
