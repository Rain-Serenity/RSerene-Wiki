# 指令列表
| 指令名稱                                    | 功能                          | 備註                                                        |
|-----------------------------------------|-----------------------------|-----------------------------------------------------------|
| /back                                   | 返回上一個保存的地點                  |                                                           |
| /balance                                | 查看你的餘額                      |                                                           |
| /baltop                                 | 查看餘額排行榜                     |                                                           |
| /co i                                   | 啟動(關閉)方塊記錄查詢模式              |                                                           |
| /dback                                  | 返回上一個死亡的地點                  |                                                           |
| /gmp mailbox                            | 打開你的郵箱，你在全球市場下架的東西都會存放在這裡   |                                                           |
| /gmp market gui                         | 打開全球市場                      |                                                           |
| /gmp market help                        | 查看全球市場的可用指令功能               |                                                           |
| /gmp market sell <價格> <數量>              | 將你手上的物品以一定的價格上架到全球市場        |                                                           |
| /money                                  | 查看你的餘額                      |                                                           |
| /msg                                    | 給某位玩家發送私聊                   |                                                           |
| /pay <玩家名> <金額>                         | 給某位玩家轉帳                     | 手續費3%                                                     |
| /ping                                   | 查看你的延遲                      |                                                           |
| /playtime                               | 查看你的在線時長                    |                                                           |
| /playtimetop                            | 查看伺服器在線時長排行榜                |                                                           |
| /removehome <你的家名稱>                     | 刪除家                         |                                                           |
| /res create <領地名>                       | 建立領地                        | 需要先使用木鋤頭選兩個點                                              |
| /res give <領地名> <玩家名>                   | 將某個領地給予一名玩家                 | 需要使用/res confirm確認                                        |
| /res help                               | 獲取領地插件的幫助                   |                                                           |
| /res pset <玩家名> <權限名> true/false/remove | 設定領地個人權限                    | 在要調整的領地內執行無需指定領地名稱，若只使用/res set <玩家名>可以打開這個玩家在此領地權限設定的GUI |
| /res remove <領地名>                       | 刪除某個領地                      | 需要使用/res confirm確認                                        |
| /res set <權限名> true/false/remove        | 設定領地全域權限                    | 在要調整的領地內執行無需指定領地名稱，若只使用/res set可以打開領地全域權限設定的GUI           |
| /rtp                                    | 隨機傳送                        | 範圍32000*32000                                             |
| /sell gui                               | 打開出售選單                      | 能出售的物品詳見"基本設定"                                            |
| /spawn                                  | 傳送到主城                       |                                                           |
| /tpa                                    | 申請傳送到其他玩家處                  |                                                           |
| /tpahere                                | 申請其他玩家傳送到你這裡                |                                                           |
| /tpsbar                                 | 開啟(關閉)查看你所在區域的TPS、MSPT等的懸浮條 |                                                           |
| /worth                                  | 查詢手上物品的出售價值                 |                                                           |
| /worthlist                              | 查詢所有可出售物品的價值                |                                                           |
