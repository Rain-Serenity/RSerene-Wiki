# 伺服器管理條例

## I. 伺服器性質與玩家守則

### 1. 伺服器性質
- **公益屬性**：雨潤伺服器是一個 Minecraft Java 版公益伺服器。
- **贊助原則**：本伺服器不包含任何付費項目，但接受玩家自願且無條件的捐助。
- **現實交易免責**：本伺服器不限制玩家在現實世界中對遊戲內物品進行有償交易，但對玩家之間引起的任何現實經濟糾紛不承擔任何法律與連帶責任。

### 2. 玩家基本守則
- **年齡建議**：根據各地區官方分級，本遊戲在歐洲 PEGI 體系下適合 **7 歲以上**，在北美 ESRB 體系下適合 **10 歲以上**，在中國大陸（CADPA）適齡提示為 **8 周歲以上**（iOS 商店分級為 9+）。如果您未滿相應年齡，建議在監護人陪同下游玩。
- **玩家公約**：請尊重並友善地對待每一位玩家。
- **帳號安全與責任**：玩家需妥善保管自己的遊戲帳號及密碼。因帳號借出、共享、出售或密碼洩露導致的物品丟失、封禁等後果，由玩家自行承擔。

### 3. 爭議處理
- 在遊玩過程中如遇問題、矛盾或爭端，請保持冷靜和理性，必要時可聯繫管理員介入協調。

## II. 服務邊界與免責聲明

### 1. 服務邊界
- 本伺服器為公益伺服器，管理團隊**僅負責**伺服器的基礎運行、規則維護及違規行為的處理，**不提供**「保姆式」個人化服務。
- 管理團隊原則上不承擔以下事項的責任：
  1. **建築與地形**：不協助玩家移動、遷移、複製、修復、重建或拆除建築群；不協助破除基岩、清理地形、製造或提供空置域。
  2. **事故與損失**：不因玩家機器故障、紅石裝置失靈、爆炸物、苦力怕、實驗失敗或誤操作等造成的物品、建築、地形損失提供理賠、回檔、補償或恢復。
  3. **玩家間糾紛**：不介入玩家之間因自願合作、借用、贈送、交易或共用設施等產生的遊戲內糾紛；但涉及作弊、偷盜、惡意破壞、惡意 PvP 等違規行為的，仍按規則處理。

### 2. 風險自擔與違規舉報
- 玩家應自行評估並承擔遊戲內建造、紅石、爆炸物及實驗操作的風險。
- 若損失係其他玩家違規造成，請保留證據並透過 QQ 群等管道舉報，管理團隊將依據規則處理。

### 3. 管理團隊援助說明
- 管理團隊是否提供額外協助由管理團隊自行決定，任何協助均不構成義務、承諾或先例。
- 請勿因未獲上述非義務協助而騷擾、辱罵或刷屏管理團隊，否則將依據本條例中「不當言論」「惡意刷屏」等規定處理。

## III. 違規行為及處理

::: warning 違規處理提示
對於以下違規行為，管理團隊將視**情節輕重**及**造成的實際影響**，給予警告、臨時封禁、永久封禁或移出社群群聊等處罰。若違規行為涉及多個帳號，將視同主號違規。
:::

### 1. 社群行為規範
- **不當言論**：發表歧視、攻擊性或嚴重不當的言論（詳見第 IV 節）。
- **不良內容**：發布色情、令人反感或過於暴力的內容。
- **惡意刷屏**：發送垃圾資訊或惡意刷屏。
- **冒充與廣告**：冒充他人、發布未經許可的廣告或進行其他不當行為。

### 2. 遊戲內行為規範
- **作弊行為**
  - 使用作弊用戶端、外掛或違規模組。
  - 惡意利用伺服器或遊戲本身的漏洞。
- **惡意破壞**
  - 未經許可破壞或篡改他人的建築與勞動成果。
  - 未經許可拿取或偷盜他人容器內的物品。
  - 惡意 PvP（在非允許區域或未經雙方同意強行擊殺玩家）。
- **濫用機制**
  - 濫用插件功能（如利用領地插件圈佔他人建築）。
  - 故意重複發送相同的指令，或使用巨集／腳本造成指令刷屏。
- **危害伺服器運行**
  - **製造卡頓**：惡意建造高頻紅石、大量堆疊實體，或利用其他機制故意造成伺服器嚴重卡頓。
  - **拒不整改**：經管理員明確警告後，仍拒不清除或整改導致卡頓的設施。
  - **屢教不改**：因卡服問題經管理員警告並整改後，再次出現同類行為的，將從重處罰，**情節嚴重的直接適用第 IV 節零容忍原則**。
- **違規建築**
  - 建造任何不雅、違規或令人反感的建築。
- **規避處罰**
  - 創建或使用小號（備用帳號）逃避封禁、刷取物資或進行違規行為。

## IV. 零容忍原則

::: danger 特別聲明
以下違規行為一經查實，將**直接予以永久封禁並移出社群群聊**，且**不接受任何形式的申訴**。
:::

### 1. 言論與隱私底線

| 違規項目              | 違規行為說明                                             |
|:--------------|:---------------------------------------------|
| **種族與性別歧視**       | 包含種族、性別歧視，或針對特定性別的攻擊言論。                            |
| **性少數族群歧視**       | 針對同性戀、跨性別等 LGBTQ+ 群體的歧視、侮辱或仇恨言論。                   |
| **特殊族群侮辱**        | 針對身心障礙者等群體的侮辱、嘲諷或仇恨言論。                             |
| **其他仇恨言論**        | 未在上文列出的其他形式仇恨言論。                                   |
| **隱私洩露**          | 未經允許洩露、傳播或倒賣他人在現實世界中的個人隱私或真實資訊。                    |
| **惡劣人身攻擊**        | 惡劣的個人人身攻擊或帶有持續騷擾性質的毒性言論。                           |

### 2. 重大惡性違規

| 違規項目              | 違規行為說明                                               |
|:--------------|:-------------------------------------------------|
| **嚴重破壞社群環境**      | 多次發表不當言論、不良內容或惡意刷屏，對社群氛圍造成嚴重破壞。                      |
| **嚴重破壞遊戲體驗**      | 情節惡劣的作弊、惡意破壞、濫用機制或違規建築，嚴重影響伺服器正常營運。                  |
| **威脅伺服器安全**       | 對伺服器進行網路攻擊（如 DDoS）、惡意探測漏洞、利用底層漏洞謀利等危害伺服器安全的行為。       |
| **惡意導致伺服器癱瘓**     | 利用超大實體炸彈、惡意區塊載入漏洞或極端紅石高頻等手段，直接導致伺服器崩潰、死鎖或大面積回檔。      |
| **現實違法關聯**        | 在遊戲內或社群群聊中，進行或宣揚現實世界中的違法犯罪活動。                        |

## V. 封禁申訴與附則

### 1. 申訴流程
- 若您對非「**零容忍原則**」的封禁處理結果存在異議，可在接到封禁通知後的 **7 天內**，透過伺服器 QQ 群等管道向管理員提交申訴，申請減輕處罰或解除封禁。逾期視為接受處罰結果。
- 違反本條例第 IV 節「零容忍原則」中任意一條的封禁，將不再受理申訴。

### 2. 附則
- **管理團隊聲明**：管理團隊成員均為義務參與伺服器管理的玩家，請尊重管理員的勞動付出。如對管理員處理結果有異議，請透過正當管道（如申訴）解決，嚴禁在群內或遊戲內對管理員進行人身攻擊、辱罵或刷屏。
- **最終解釋權**：本管理團隊保留對伺服器管理條例的最終解釋權及修訂權。
- **服規修訂**：本管理條例將根據伺服器實際營運情況不定期進行修訂。新規發布後即時生效，如有衝突，以最新版本為準。
