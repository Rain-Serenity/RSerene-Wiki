## 序章：疾風掠過155, 81, -377
陽光穿透雲層灑落在座標為 `(155, 81, -377)` 的草甸之上，沒有指令賦予的神力，沒有模組加持的特效，唯有皮革護甲摩擦的風聲，與史萊姆球撞擊地面的脆響。
**流光逐影** 是專為純淨生存玩家打造的足球盛會：它不考驗裝備強度，只考驗奔跑的速度、傳球的精度，和團隊配合的默契度。踏上這片綠茵，讓速度成為你的語言，讓進球成為唯一的迴響。

## 賽事核心依託
本次賽事完全基於純淨生存原生機制設計，三大核心支撐如下：
1. **硫方塊球物理特性**：採用原版填充羊毛硫方塊作為比賽用球，還原足球的彈跳、滾動、碰撞反饋，無需任何自訂道具
2. **生存原生規則**：全程禁用作弊指令，所有操作符合純淨生存服日常約束

## 參賽規則
### 參賽資格
- 僅限純淨生存、空島服**無封禁記錄**的玩家報名
- 以隊伍為單位參賽，每隊4人，<strong>填寫<a href="https://docs.qq.com/sheet/DUkNOSU1mclV2Z2FD" style="color:#3498db;text-decoration:underline;">表格</a></strong>進行活動報名
- 單人最多同時加入**1支**隊伍，不得跨隊參賽

### 硬性要求
- 比賽期間必須穿戴**無附魔皮革護甲**，嚴禁穿戴鑽石/獄髓護甲、鞘翅、冰霜行者附魔靴子
- 比賽用球統一由主辦方在開賽前發放，**禁止自帶道具**
- 玩家使用**擊退I木棍**或者**身體撞擊**來控制硫磺塊移動

### 禁止行為
- 使用飛行、加速、穿牆等**作弊客戶端**功能
- **惡意破壞**比賽場地、**干擾裁判**判罰、**辱罵參賽人員**
- 故意**拖延比賽時間**、利用地形**卡球**阻礙正常進攻
- 違反上述規則者將直接**取消參賽資格，情節嚴重者追加封禁處罰**

::: warning 裝備限制提醒
比賽開場前裁判將逐一核查參賽人員裝備，穿戴帶有保護、荊棘、擊退等戰鬥附魔的護甲將直接判負當場比賽，請勿抱有僥倖心理。
:::

## 賽事流程
1. **淘汰賽**：進行交叉比賽，隨機分配，全勝者為冠軍
2. **排名賽**：淘汰賽敗者繼續進行比賽直至決出排名

::: tip 比賽用球管理
比賽過程中若球飛出場地，由邊裁將球擲回界內，嚴禁玩家自行撿取場外球；若球意外消失，裁判將立即暫停比賽，重新投放官方用球後從斷點繼續。
:::

::: warning 觀賽須知
觀賽玩家需待在觀眾席區域內，嚴禁進入比賽場地、投擲雞蛋/雪球等物品干擾比賽，違者將被傳送出場地並暫時取消觀賽資格。
:::
