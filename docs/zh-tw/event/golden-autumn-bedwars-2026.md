## 🎯 活動主題與定位

**「雨潤九州·金秋床戰」國慶起床戰爭特別活動** —— 國慶假期期間，在雨潤活動服進行團隊起床戰爭對抗。玩家以小隊為單位，守護本隊床、拆除敵方床、淘汰對手，爭奪金秋床戰冠軍。

為什麼辦？雨潤一直堅持公益、友善、公平的社群氛圍。這次國慶活動不改變生存服原有玩法，而是在**獨立活動服**中開啟起床戰爭小遊戲，讓新老玩家都能輕鬆參與，體驗團隊配合、戰術拆床和國慶狂歡。

**起床戰爭三大核心**：

1. **守床**：床是本隊生命線，床在則隊友可復活，床毀則全隊進入淘汰倒計時
2. **拆床**：通過搭路、偷襲、團戰、陷阱等方式摧毀敵方床，是獲勝關鍵
3. **團隊配合**：資源分配、防守回防、正面牽制、側翼偷家，缺一不可

## 🏆 賽制與計分

**比賽模式**
- 小組積分賽 + 四強決賽
- 每局以官方起床戰爭地圖為準，具體人數按報名情況調整
- 每局目標：保護本隊床，拆除敵方床，淘汰全部敵人

**積分規則**

| 行為         | 積分         |
|------------|------------|
| 獲勝         | +5         |
| 拆除敵方床      | +2 / 張     |
| 擊殺         | +1 / 人     |
| 最終存活       | +1         |
| 失敗但拆床      | 仍計拆床分     |

**排名規則**
- 按總積分排名，積分相同依次比較：拆床數 → 擊殺數 → 總存活時間 → 勝負關係
- 四強進入決賽，決賽採用三局兩勝制
- 超時未決出勝負時，按剩餘床數、擊殺數、拆床數判定
