# 指令列表
::: warning 注意
空島伺服器已於2026.7.29日獨立於雨潤伺服器運營，以下資訊截止於2026.7.29且不再更新。
:::
| 指令名稱            | 功能                | 備註 |
|-----------------|-------------------|----|
| /rim tips       | 查看小提示             |    |
| /rim recipemenu | 查看特殊合成表           |    |
| /rim slime      | 查看史萊姆區塊           |    |
| /tpsbar         | 開啟(關閉)查看你所在區域的TPS、MSPT等的懸浮條 |    |
| /plot auto      | 領取你的島嶼            |    |
| /plot home      | 回到你的島嶼            |    |
| /plot setbiome  | 設定你的島嶼的生態系       |    |
| /plot sethome   | 設定你的島嶼傳送位置        |    |
