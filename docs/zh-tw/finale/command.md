# 指令列表
::: tip 提示
本伺服器按整合包原版運行，未新增自訂伺服器指令；下列為遊戲內可用的原版指令。
:::
| 指令名稱        | 功能              | 備註        |
|-------------|-----------------|-----------|
| /seed       | 查看目前世界的種子       |           |
| /spawnpoint | 設定個人出生點         |           |
| /locate     | 尋找最近的生物群系或結構    | 需要管理員權限   |
| /trigger    | 觸發管理員預先設定的記分板事件 | 由管理員設定後使用 |
