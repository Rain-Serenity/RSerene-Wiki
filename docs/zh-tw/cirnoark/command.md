# 指令列表
::: tip 提示
完美算術工坊伺服器由 Korvahet 營運。
:::

| 指令名稱                       | 功能                        | 備註                        |
|----------------------------|---------------------------|---------------------------|
| /back                      | 返回上一個保存的地點                |                           |
| /balance                   | 查看你的餘額                    |                           |
| /baltop                    | 查看餘額排行榜                   |                           |
| /co i                      | 啟動（關閉）方塊記錄查詢模式            |                           |
| /dback                     | 返回上一個死亡的地點                |                           |
| /gmp mailbox               | 打開你的郵箱，你在全球市場下架的東西都會存放在這裡 |                           |
| /gmp market gui            | 打開全球市場                    |                           |
| /gmp market help           | 查看全球市場的可用指令功能             |                           |
| /gmp market sell <價格> <數量> | 將你手上的物品以一定的價格上架到全球市場      |                           |
| /home                      | 傳送到你的家                    |                           |
| /homes                     | 查看你的所有家                   |                           |
| /money                     | 查看你的餘額                    |                           |
| /msg                       | 給某位玩家發送私聊                 |                           |
| /pay <玩家> <金額>             | 給某位玩家轉帳                   | 手續費 3%                    |
| /ping                      | 查看你的延遲                    |                           |
| /playtime                  | 查看你的在線時長                  |                           |
| /playtimetop               | 查看伺服器在線時長排行榜              |                           |
| /removehome <家名稱>          | 刪除家                       |                           |
| /res create <領地名>          | 建立領地                      | 需要先用木鋤頭選兩個點               |
| /res info <領地名>            | 查看領地資訊                    |                           |
| /res list                  | 列出你的所有領地                  |                           |
| /res padd <玩家> <權限>        | 給某位玩家新增領地權限               | 只能新增建造、破壞、容器、互動等權限        |
| /res remove <領地名>          | 刪除某個領地                    |                           |
| /res set <權限> true/false   | 設定領地全域權限                  | 在要調整的領地內執行                |
| /res sethome <領地名>         | 設定領地內傳送點                  |                           |
| /rtp                       | 隨機傳送                      | 範圍 3200 ~ 32000，冷卻 10 分鐘  |
| /sell gui                  | 出售背包中的物品                  | 可出售的物品詳見「基本設定」            |
| /sf                        | 開啟黏液科技主選單                 | 包含指南、配方查詢與研究進度            |
| /sf guide                  | 開啟黏液科技新手指南                | 第一次進服會自動收到一份              |
| /sfcalc calc <物品> [數量]     | 計算某個物品所需的材料               | 也可簡寫為 /sfc calc <物品> [數量] |
| /sethome <家名稱>             | 設定一個家                     | 最多可設定 8 個                 |
| /spawn                     | 傳送到主城                     |                           |
| /tpa <玩家>                  | 申請傳送到其他玩家處                | 請求 60 秒內有效                |
| /tpahere <玩家>              | 申請其他玩家傳送到你這               |                           |
| /worth                     | 查詢手上物品的出售價值               |                           |
| /worthlist                 | 查詢所有可出售物品的價值              |                           |

::: tip 提示
聊天時輸入 `[inv]`、`[ender]`、`[item]` 可以直接展示背包、末影箱和手持物品；`玩家名` 可以提及某位玩家。
:::
