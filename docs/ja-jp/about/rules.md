# サーバー管理規則

## I. サーバーの性質とプレイヤー規範

### 1. サーバーの性質
- **非営利の性質**：Rain Serenity は Minecraft Java Edition の非営利サーバーです。
- **寄付の原則**：本サーバーには有料コンテンツは一切ありませんが、プレイヤーからの自発的かつ無条件の寄付を受け付けています。
- **現実取引の免責**：本サーバーはプレイヤーが現実世界でゲーム内アイテムを金銭取引することを制限しませんが、プレイヤー間で生じた現実の経済紛争について一切の法的・連帯責任を負いません。

### 2. プレイヤー基本規範
- **年齢の目安**：各地域の公式レーティングに従い、本ゲームは欧州の PEGI 体系では **7 歳以上**、北米の ESRB 体系では **10 歳以上**、中国本土（CADPA）では **8 歳以上**（iOS App Store のレーティングは 9+）に適しています。該当年齢に満たない場合は、保護者の同伴の下でプレイすることをおすすめします。
- **プレイヤー規範**：すべてのプレイヤーを尊重し、友好的に接してください。
- **アカウント安全と責任**：プレイヤーは自己のゲームアカウントとパスワードを適切に管理する必要があります。アカウントの貸与・共有・売却やパスワード漏洩によるアイテム喪失、BAN 等の結果はプレイヤー自身が負います。

### 3. 争議の処理
- プレイ中に問題・衝突・争議が生じた場合は冷静かつ理性的に行動し、必要に応じて管理者に連絡して調整を求めてください。

## II. サービスの境界と免責事項

### 1. サービスの境界
- 本サーバーは非営利サーバーであり、管理チームはサーバーの基本運営・規則の維持・違反行為の処理**のみ**を担当し、「お世話係」のような個別サービスは**提供しません**。
- 管理チームは原則として以下について責任を負いません：
  1. **建築と地形**：プレイヤーの建築・建築群の移動・移転・複製・修復・再建・撤去を支援しません。岩盤の破砕、地形の整理、空き領域の作成・提供も支援しません。
  2. **事故と損失**：プレイヤーのマシン故障、レッドストーン装置の誤作動、爆発物、クリーパー、実験失敗や誤操作によるアイテム・建築・地形の損失について、補償・ロールバック・弁償・復元は行いません。
  3. **プレイヤー間の紛争**：自発的な協力・貸借・贈与・取引・施設共用から生じたゲーム内紛争には介入しません。ただし、チート・窃盗・悪意ある破壊・悪意ある PvP 等の違反行為は規則に従って処理します。

### 2. 自己責任のリスクと違反の通報
- プレイヤーはゲーム内の建築・レッドストーン・爆発物・実験操作のリスクを自己評価し、自己負担するものとします。
- 損失が他のプレイヤーの違反による場合は証拠を保存し、QQ グループ等の手段で通報してください。管理チームが規則に従って処理します。

### 3. 管理チームの援助に関する説明
- 管理チームが追加の援助を行うかどうかは管理チームが独自に判断します。いかなる援助も義務・確約・前例を構成するものではありません。
- 上記の非義務的援助を受けられなかったことを理由に管理チームへ嫌がらせ・辱罵・スパムを行わないでください。その場合は本規則の「不適切な発言」「悪意あるスパム」等の規定に従って処理されます。

## III. 違反行為と処理

::: warning 違反処理に関するお知らせ
以下の違反行為について、管理チームは**行為の重大性**および**実際に与えた影響**に応じ、警告・一時的 BAN・永久 BAN・コミュニティグループチャットからの削除等の処罰を行います。違反行為が複数アカウントに及ぶ場合は、メインアカウントの違反とみなします。
:::

### 1. コミュニティ行動規範
- **不適切な発言**：差別的・攻撃的または重大な不適切発言（詳細は第 IV 節）。
- **有害なコンテンツ**：アダルト・忌避感を与える・過度に暴力的なコンテンツの投稿。
- **悪意あるスパム**：迷惑メッセージの送信や悪意あるスパム。
- **成り済ましと広告**：他人への成り済まし、無許可の広告投稿、その他不適切な行為。

### 2. ゲーム内行動規範
- **チート**
  - チートクライアント・チートツール・違反 MOD の使用。
  - サーバーやゲームの脆弱性の悪用。
- **悪意ある破壊**
  - 無許可で他人の建築・作業成果を破壊・改変すること。
  - 無許可で他人のコンテナ内のアイテムを取得・窃盗すること。
  - 悪意ある PvP（非許可区域や双方の合意なしにプレイヤーを強制的にキルすること）。
- **メカニズムの悪用**
  - プラグイン機能の悪用（例：土地保護プラグインで他人の建築を囲うこと）。
  - 同一コマンドの意図的な繰り返し送信、またはマクロ・スクリプトによるコマンドスパム。
- **違反建築**
  - いかなる不雅・違反・忌避感を与える建築物の建設。
- **処罰回避**
  - BAN 回避・物資の取得・違反行為のためのサブアカウント（予備アカウント）の作成・使用。

## IV. ゼロトレランス原則

::: danger 特別声明
以下の違反行為は確認され次第、**直ちに永久 BAN とコミュニティグループチャットからの削除**が行われ、**いかなる形式の申し立ても受け付けません**。
:::

### 1. 言論とプライバシーの下限線

| 違反項目            | 違反行為の説明                                    |
|:------|:------------|
| **人種・性別差別**     | 人種・性別差別、または特定の性別への攻撃を含む発言。                 |
| **LGBTQ+ 差別**   | 同性愛・トランスジェンダー等の LGBTQ+ 集団に対する差別・侮辱・憎悪発言。   |
| **障害者等への侮辱**    | 障害者等の集団に対する侮辱・嘲弄・憎悪発言。                     |
| **その他の憎悪発言**    | 上記に列挙されていないその他の形式の憎悪発言。                    |
| **プライバシー漏洩**    | 他者の現実世界の個人プライバシーや実情報を無断で漏洩・拡散・転売すること。      |
| **悪質な個人攻撃**     | 悪質な個人攻撃、または継続的な嫌がらせの性質を持つ有害な発言。            |

### 2. 重大な悪性違反

| 違反項目                 | 違反行為の説明                                                              |
|:------|:------------|
| **コミュニティ環境の深刻な破壊**   | 不適切な発言・有害コンテンツ・悪意あるスパムを繰り返し、コミュニティの雰囲気を深刻に破壊すること。                    |
| **ゲーム体験の深刻な破壊**      | 悪質なチート・破壊・メカニズム悪用・違反建築で、サーバーの正常運営に重大な影響を与える行為。                       |
| **サーバー安全への脅威**       | サーバーへのネットワーク攻撃（DDoS 等）、脆弱性の悪意ある探索、低レベル脆弱性を利用した利益獲得など、サーバー安全を脅かす行為。   |
| **現実違法との関連**         | ゲーム内やコミュニティグループチャットで、現実世界の違法・犯罪行為を行いまたは宣伝すること。                       |

## V. BAN の申し立てと附則

### 1. 申し立ての流れ
- 「**ゼロトレランス原則**」に該当しない BAN の処理結果に異議がある場合は、BAN 通知を受けた後 **7 日以内**に、サーバー QQ グループ等の手段で管理者に申し立てを提出し、処罰の軽減または BAN 解除を申請できます。期限超過は処罰結果の受諾とみなします。
- 本規則第 IV 節「ゼロトレランス原則」のいずれかに違反した BAN は、以後申し立てを受け付けません。

### 2. 附則
- **管理チーム声明**：管理チームのメンバーはすべてサーバー管理に自発的に参加しているプレイヤーです。管理者の労力を尊重してください。管理者の処理結果に異議がある場合は、正当な手段（申し立て等）で解決し、グループ内やゲーム内で管理者への個人攻撃・辱罵・スパムを厳禁します。
- **最終解釈権**：本管理チームはサーバー管理規則の最終解釈権および改訂権を留保します。
- **規則の改訂**：本管理規則はサーバーの実際の運営状況に応じて不定期に改訂されます。新規は公開後即時発効し、矛盾がある場合は最新版を優先します。
