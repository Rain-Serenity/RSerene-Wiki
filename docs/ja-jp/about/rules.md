# サーバールール

## I. 総則

### 1. **非営利性**
- Minecraft Rain Serenity Server は非営利の無料Minecraft Java Editionサーバーです。

### 2. **寄付ポリシー**
- このサーバーには有料アイテムやPay-to-Win要素はありませんが、無条件の自主的な寄付を受け付けています。

### 3. **RMT免責事項**
- このサーバーはプレイヤーがゲーム内アイテムを現実世界の通貨と交換することを制限しませんが、サーバー運営チームはプレイヤー間の現実世界の経済的紛争に対して一切の責任を負いません。

### 4. **紛争解決**
- サーバーでのプレイ中に問題、紛争、または議論が発生した場合は、冷静かつ合理的に対処し、必要に応じて管理者に連絡して対応を依頼してください。

### 5. **コミュニティの尊重**
- 他のプレイヤーを尊重し、すべての人に親切に接してください。

### 6. **年齢ガイドライン**
- Mojangの公式ガイドラインによると、Minecraftの推奨最低年齢は9歳以上です。これ以下の年齢の場合は、保護者の監督下でプレイしてください。

### 7. **サービス範囲と免責事項**
- 本サーバーは公益サーバーであり、管理チームはサーバーの基本運営、規則の執行、明確な違反行為の処理**のみ**を担い、「保姆式」の個別サービスは**提供しません**。
- 管理チームは原則として以下の事項を受け付けず、負担も補償も行いません：
  1. **建築と地形**：プレイヤーによる建築物の移動・移設・複製・修復・再建築・解体の援助は行いません。ブロックの破壊、地形の整備、空域の作成・提供も行いません。
  2. **事故と損失**：マシンのクラッシュ、レッドストーン装置の故障、爆発物、クリーパー、実験の失敗、誤操作等によるアイテム・建築・地形の損失に対する保証、ロールバック、補償、復旧は行いません。
  3. **プレイヤー間の紛争**：自発的な協力、借用、贈与、取引、機械・施設の共用等から生じるゲーム内の紛争には介入しません。ただし、チート、窃盗、悪意ある破壊、悪意あるPvP等の違反行為は規則に従って処理します。
- プレイヤーは、ゲーム内の建築、レッドストーン、爆発物、実験操作のリスクを自ら評価し、負ってください。
- 損失が他のプレイヤーの規則違反によるものである場合は、証拠を保全し、QQグループ等を通じて報告してください。管理チームは規則に従って対応します。
- 追加の支援を行うかどうかは管理チームの裁量によるものであり、いかなる支援も義務、約束、先例となるものではありません。
- 上記の非義務的な支援を得られなかったことを理由に管理チームへの嫌がらせ、罵倒、スパムを行わないでください。違反した場合、本規則の「不適切な発言」「悪意あるスパム」等の条項に基づき処理されます。

## II. 禁止行為

::: warning ペナルティ通知
**違反が発見された**が**重大な結果を招いていない**場合、管理チームは**重大度に応じて** **警告、一時的なBAN**、または**削除** の対象とします。
:::

### 1. コミュニティ行動規範

* **不適切な発言**
   * 差別的、攻撃的、または著しく不適切な発言をすること。 *(下記セクションIIIを参照)*
* **不快なコンテンツ**
   * ポルノ、不快、または過度に暴力的なコンテンツを投稿すること。
* **スパム**
   * チャットにスパムや過剰なメッセージを送信すること。
* **不適切な行為**
   * 他人になりすますこと、許可なく広告を行うこと、またはその他不適切な行為を行うこと。

### 2. ゲーム内行動

**チート**
* a. チートクライアント、ハック、または禁止されたModを使用すること。
* b. サーバーやバニラゲームの脆弱性を悪意を持って悪用すること。

**グリーフィング**
* a. 他のプレイヤーの建造物を無断で破壊または改変すること。
* b. 他のプレイヤーのコンテナからアイテムを盗むこと。
* c. 相互同意なしの悪意のあるPvPまたはプレイヤーキル（PK）。

**メカニクスの悪用**
* a. プラグイン機能の悪用（例：他人の建造物を保護で囲う）。
* b. サーバーコマンドのスパム送信。

**違法建造物**
* 不適切、わいせつ、または不快な建造物を建てること。

## III. ゼロトレランス違反

::: danger 極めて重要 | 絶対的なレッドライン
以下の行為は **事前警告なしの即時永久BANおよびコミュニティグループからの削除** となります。これらの罰則は最終的なものであり、異議申し立ては一切受け付けません。
:::

### 1. ヘイトスピーチ＆ハラスメント

| 違反                | 説明                                                                 |
|:--------------------|:---------------------------------------------------------------------|
| **人種差別**        | 人種的中傷や人種差別的ヘイトスピーチ。                                 |
| **性差別**          | 性差別的発言やジェンダーに基づく差別。                                 |
| **反LGBTQ+**        | 同性愛嫌悪、トランスフォビア的な中傷、または反LGBTQ+スピーチ。          |
| **障害者差別**      | 障害者を標的にした中傷やヘイトスピーチ。                               |
| **その他のヘイトスピーチ** | 上記に記載されていないその他の形態のヘイトスピーチ。                   |
| **個人情報暴露**    | 他人の現実世界の個人情報を暴露、漏洩、または配布すること。             |
| **深刻な嫌がらせ**  | 深刻な個人攻撃または有害なハラスメント。                               |

### 2. II. 禁止行為に違反し、重大な結果を招いた場合

| 違反                        | 説明                                                                 |
|:----------------------------|:---------------------------------------------------------------------|
| **コミュニティ規範の重大な違反** | 不適切な発言、不快なコンテンツ、悪意のあるスパムなど、重大な結果を招く違反行為。 |
| **ゲーム内規則の重大な違反**   | チート、グリーフィング、メカニクスの悪用、違法建造物など、サーバー体験を著しく損なう行為。 |

## IV. BAN異議申し立て

### 1. 異議申し立てを受け付けない場合
- いずれかのゼロトレランス違反に抵触した場合。

### 2. 異議申し立ての手続き
- 「ゼロトレランス違反」以外の違反によるBANに同意できない場合は、サーバーのQQグループなどのチャネルを通じて管理者に異議申し立てを提出し、罰則の軽減またはBAN解除をリクエストできます。
