# よくある質問

## I. ログインと参加関連
### Q1：正版アカウントは必要ですか？
A：不要です。正版・オフラインどちらのアカウントもそのまま入室でき、ホワイトリスト申請は不要です。

### Q2：パックはどこでダウンロードできますか？
A：QQグループ 902620497 の**グループファイル**からダウンロードしてください。原本のパックを使用し、mod を自分で増減しないでください。原作者の公開ページを検索して入手することもできます。

### Q3：サーバーへの参加方法は？
A：1. QQグループ 902620497 に参加し、**グループファイル**から「Closing Song」パックをダウンロード；<br>
2. PCL、HMCL などのランチャーで直接「パックをインポート」し、自分で再インストールや mod の増減をしない；<br>
3. 起動後、バージョンが 1.20.1-Forge で Java 17 を使用していることを確認；<br>
4. マルチプレイ → サーバーを追加、アドレスは `CLSO.RSerene.com`；<br>
5. 初回入室時に管理者から初心者物資を受け取れます。詳細はグループ公告で確認してください。

### Q4：なぜ接続できない・何度も再接続になるのですか？
A：まずバージョンが 1.20.1-Forge で Java 17 を使用しており、mod がパックと一致しているか確認してください。アドレスは `CLSO.RSerene.com` です。それでも接続できない場合はグループで尋ねてください。アドレスが変更された可能性があります。

### Q5：お金はかかりますか？
A：かかりません。プレイは無料です（寄付は完全に自発的で強制ではありません）。

## II. サーバーの仕組みとルール
### Q1：サーバーは何人まで入れますか？
A：同時接続は約15人までです。満員時は入れません。少し待つか、グループで尋ねてください。

### Q2：ワールドは削除されますか？
A：されません。パックを変更する際は、まず旧ワールドをバックアップしてから変更します。

### Q3：いつパックが変更されますか？
A：現在のパックを一通り遊び終えたら変更します。変更前にグループで投票・公告を行います。

### Q4：ラグや切断が発生したらどうすればよいですか？
A：まずグループ公告に再起動予定がないか確認してください。多数が同時に切断した場合は、通常サーバー再起動またはネットワークの変動です。少し待ってから再接続してください。

### Q5：サーバーにはどんなルールがありますか？
A：ハック、透視、飛行、自動放置、スクリプトによるアイテム生成は禁止。悪意あるPvP、家荒らし、他人の建築破壊、スパム、暴言も禁止。バニラのレッドストーン機構やモブトラップは使用できますが、意図的にサーバーを重くする行為やチャンクローダーの悪用は禁止です。具体的な条項はグループ公告に準じます。

## III. 著作権とコミュニティ
### Q1：パックを独自に配布・販売できますか？
A：できません。本サーバーはプレイヤーから一切の費用を徴収せず、パックをいかなる形でも販売・有償配布しません。パックは本サーバーのプレイヤーが通常プレイするためにのみ使用されます。

### Q2：問題はどこへ報告すればよいですか？
A：ゲーム内でオンライン管理者に問い合わせるか、公式QQグループ 902620497 に参加してグループ内で @管理者 または @Chosen-1st にご連絡ください。
