# コマンド一覧
::: tip ヒント
本サーバーはパック原本で稼働しており、独自のサーバーコマンドは追加していません。以下はゲーム内で使えるバニラコマンドです。
:::
| コマンド        | 機能                         | 備考           |
|-------------|----------------------------|--------------|
| /seed       | 現在のワールドのシードを確認する           |              |
| /spawnpoint | 個人のスポーン地点を設定する             |              |
| /locate     | 最も近いバイオームや構造物を探す           | 管理者権限が必要     |
| /trigger    | 管理者が事前に設定したスコアボードイベントを実行する | 管理者が設定後に使用可能 |
