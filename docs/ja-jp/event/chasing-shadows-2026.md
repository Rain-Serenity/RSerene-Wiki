> 対応バージョン：**Minecraft Java Edition 26.2（Chaos Cubed）**

> 本イベントは**Minecraft 公式イベントではありません**。Mojang / Microsoft とは無関係です

## 序幕：風が155, 81, -377を駆け抜ける
陽光が雲を透かし、座標 `(155, 81, -377)` の草原に降り注ぐ。コマンドの力も、MODの特效もない。ただ革の鎧が擦れる風音と、スライムボールが地面を打つ乾いた音だけが響く。
**流光逐影**は、サバイバルモードのプレイヤーのために作られたサッカーの祭典だ。装備の強さではなく、走る速さ、パスの正確さ、チームワークの息の合い方が試される。この緑のフィールドに立ち、速さを言葉に、ゴールを唯一の響きにしよう。

## 競技の核となる仕組み
本大会はすべてバニラサバイバルのネイティブ仕様に基づいて設計されている：
1. **硫黄ブロックの物理特性**：バニラの羊毛入り硫黄ブロックをサッカーボールとして使用。バウンド、転がり、衝突の反応を再現。カスタムアイテムは一切不要
2. **サバイバルネイティブルール**：全行程でチートコマンド禁止。すべての操作はサバイバルサーバーの日常的な制約に従う

## 参加規則
### 参加資格
- サバイバルサーバーまたはスカイブロックサーバーで**BANされていない**プレイヤーのみ参加可能
- 4人1チームで登録。<strong><a href="https://docs.qq.com/sheet/DUkNOSU1mclV2Z2FD" style="color:#3498db;text-decoration:underline;">フォーム</a>に記入</strong>して申し込んでください
- 1人のプレイヤーは**1つ**のチームにのみ所属可能

### 必須要件
- 試合中は**エンチャントなしの革の鎧**を着用必須。ダイヤモンド/ネザライトの鎧、エリトラ、フロストウォーカーのブーツは禁止
- 試合球は主催者が試合開始前に配布。**持ち込み禁止**
- プレイヤーは**ノックバックIの棒**または**体当たり**で硫黄ブロックを操作

### 禁止行為
- 飛行、高速移動、壁抜け等の**チートクライアント**機能の使用
- **フィールドの破壊**、**審判妨害**、**参加者への誹謗中傷**
- 意図的な**試合遅延**、地形を利用した**ボールのトラップ**
- 違反者は**即時失格**。重大な場合は**BAN処分**

::: warning 装備制限の注意
試合開始前に審判が全参加者の装備を確認します。ダメージ軽減、棘の鎧、ノックバック等の戦闘エンチャントが付与された防具を着用している場合は即敗戦となります。油断しないでください。
:::

## 試合形式
1. **トーナメント戦**：クロスマッチ、ランダム割り当て。全勝チームが優勝
2. **順位決定戦**：トーナメント敗者が順位をかけて継続試合

::: tip 試合球の管理
試合中にボールがフィールド外に出た場合、線審がボールを投げ入れます。プレイヤーが自分でボールを拾うことは禁止されています。ボールが消失した場合、審判が直ちに試合を中断し、新しいボールを投入して中断箇所から再開します。
:::

::: warning 観戦ルール
観戦者は指定されたエリア内に留まってください。フィールドへの侵入、卵や雪玉の投擲による妨害は、観戦エリアから退場となり観戦資格を一時停止します。
:::
