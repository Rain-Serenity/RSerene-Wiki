## 🎯 イベントテーマとコンセプト

**「雨潤九州・金秋ベッドウォーズ」国慶節ベッドウォーズ特別イベント** —— 国慶節の休暇期間中、RSereneイベントサーバーでチームによるベッドウォーズ対戦を行います。プレイヤーは小隊を単位に自軍のベッドを守り、敵のベッドを破壊し、敵を撃破して、金秋ベッドウォーズのチャンピオンを競います。

なぜ開催するのか？RSereneは一貫して公益的で友好的、公平なコミュニティを大切にしてきました。今回の国慶節イベントはサバイバルサーバーの既存のゲームプレイを変えず、**専用イベントサーバー**でベッドウォーズのミニゲームを開始します。新規・古参プレイヤー誰でも簡単に参加でき、チームワーク、戦術的なベッド破壊、国慶節の祝祭を楽しめます。

**ベッドウォーズの3つの核心**：

1. **ベッドの防衛**：ベッドは自軍の生命線。ベッドがあれば味方がリスポーンでき、破壊されると全員が脱落カウントダウンに入る
2. **ベッドの破壊**：橋をかけ、奇襲、集団戦、トラップなどで敵のベッドを破壊することが勝利の鍵
3. **チームワーク**：資源配分、防衛と交代、正面からの牽制、側面からの奇襲、どれも欠かせない

## 🏆 開催形式とスコア

**試合モード**
- グループポイント戦 + トップ4決勝戦
- 各試合は公式ベッドウォーズマップを使用し、参加状況に応じて人数を調整
- 各試合の目標：自軍のベッドを守り、敵のベッドを破壊し、敵を全滅させる

**得点ルール**

| アクション           | ポイント                 |
|------------------|----------------------|
| 勝利               | +5                   |
| 敵のベッド破壊        | +2 /個                |
| キル               | +1 /人                |
| 最後の生存者          | +1                   |
| 敗北したがベッド破壊     | ベッド破壊ポイントは加算         |

**順位決定ルール**
- 総積点で順位を決定。同点の場合は次の順で比較：ベッド破壊数 → キル数 → 総生存時間 → 直接対戦の結果
- 上位4チームが決勝へ進み、決勝は3番勝負
- 時間切れで決着しない場合は、残りベッド数・キル数・ベッド破壊数で判定
