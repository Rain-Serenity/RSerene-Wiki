# コマンド一覧
::: tip ヒント
CirnoArk サーバーは Korvahet が運営しています。
:::

| コマンド                       | 機能                                              | 備考                              |
|----------------------------|-------------------------------------------------|---------------------------------|
| /back                      | 直前の保存地点に戻る                                      |                                 |
| /balance                   | 残高を確認する                                         |                                 |
| /baltop                    | 残高ランキングを表示する                                    |                                 |
| /co i                      | ブロック記録の照会モードをオン（オフ）にする                          |                                 |
| /dback                     | 直前の死亡地点に戻る                                      |                                 |
| /gmp mailbox               | 自分のメールボックスを開く。グローバルマーケットから取り下げたアイテムはすべてここに保管される |                                 |
| /gmp market gui            | グローバルマーケットを開く                                   |                                 |
| /gmp market help           | グローバルマーケットで利用できるコマンドを表示する                       |                                 |
| /gmp market sell <価格> <数量> | 手に持っているアイテムを指定した価格でグローバルマーケットに出品する              |                                 |
| /home                      | 自分の家へテレポートする                                    |                                 |
| /homes                     | 自分の家をすべて一覧表示する                                  |                                 |
| /money                     | 残高を確認する                                         |                                 |
| /msg                       | プレイヤーにプライベートメッセージを送る                            |                                 |
| /pay <プレイヤー> <金額>          | プレイヤーに送金する                                      | 手数料 3%                          |
| /ping                      | 自分のレイテンシを確認する                                   |                                 |
| /playtime                  | 自分のプレイ時間を確認する                                   |                                 |
| /playtimetop               | サーバーのプレイ時間ランキングを表示する                            |                                 |
| /removehome <家の名前>         | 家を削除する                                          |                                 |
| /res create <領地名>          | 領地を作成する                                         | 先に木のクワで 2 点を選択する必要がある           |
| /res info <領地名>            | 領地の情報を表示する                                      |                                 |
| /res list                  | 自分の領地をすべて一覧表示する                                 |                                 |
| /res padd <プレイヤー> <権限>     | プレイヤーに領地の権限を追加する                                | 追加できるのは建築・破壊・コンテナ・インタラクトなどの権限のみ |
| /res remove <領地名>          | 領地を削除する                                         |                                 |
| /res set <権限> true/false   | 領地の全体権限を設定する                                    | 変更したい領地の中で実行する                  |
| /res sethome <領地名>         | 領地内のテレポート地点を設定する                                |                                 |
| /rtp                       | ランダムテレポート                                       | 範囲 3200 ~ 32000、クールダウン 10 分     |
| /sell gui                  | インベントリのアイテムを売却する                                | 売却できるアイテムは「基本設定」を参照             |
| /sf                        | Slimefun のメインメニューを開く                            | ガイド・レシピ検索・研究進捗を含む               |
| /sf guide                  | Slimefun の初心者ガイドを開く                             | 初参加時に自動で配布される                   |
| /sfcalc calc <アイテム> [数量]   | アイテムに必要な素材を計算する                                 | /sfc calc <アイテム> [数量] と略記も可     |
| /sethome <家の名前>            | 家を設定する                                          | 最大 8 件まで                        |
| /spawn                     | メインシティへテレポートする                                  |                                 |
| /tpa <プレイヤー>               | 他のプレイヤーへのテレポートを申請する                             | 申請は 60 秒間有効                     |
| /tpahere <プレイヤー>           | 他のプレイヤーに自分の場所へのテレポートを申請する                       |                                 |
| /worth                     | 手に持っているアイテムの売却価格を確認する                           |                                 |
| /worthlist                 | 売却可能なすべてのアイテムの価格を確認する                           |                                 |

::: tip ヒント
チャットで `[inv]`、`[ender]`、`[item]` を入力すると、インベントリ・エンダーチェスト・手持ちアイテムがそのまま表示されます。`プレイヤー名` でプレイヤーをメンションできます。
:::
