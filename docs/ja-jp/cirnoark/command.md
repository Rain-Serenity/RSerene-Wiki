# コマンド一覧
::: tip ヒント
CirnoArk サーバーは Korvahet が運営しています。
:::

| コマンド | 機能 | 備考 |
|---|---|---|
| /back | 直前の保存地点に戻ります |  |
| /balance | 残高を確認します |  |
| /baltop | 残高ランキングを表示します |  |
| /co i | ブロック記録の照会モードを切り替えます |  |
| /dback | 直前の死亡地点に戻ります |  |
| /home | 自分の家へテレポートします |  |
| /homes | すべての家の一覧を表示します |  |
| /msg | 他のプレイヤーに個人チャットを送ります |  |
| /money | 残高を確認します |  |
| /pay <プレイヤー> <金額> | 他のプレイヤーに送金します | 手数料 3% |
| /ping | 自分の遅延を確認します |  |
| /playtime | オンライン時間を確認します |  |
| /playtimetop | オンライン時間ランキングを表示します |  |
| /removehome <家の名前> | 家を削除します |  |
| /res create <領地名> | 領地を作成します | 先に木の hoe で二つの点を選びます |
| /res info <領地名> | 領地の情報を表示します |  |
| /res list | すべての領地の一覧を表示します |  |
| /res padd <プレイヤー> <権限> | プレイヤーに領地の権限を与えます | 建築・破壊・コンテナ・操作のみ |
| /res remove <領地名> | 領地を削除します |  |
| /res set <権限> true/false | 領地の全体権限を設定します | 調整したい領地内で実行します |
| /res sethome <領地名> | 領地内のテレポート地点を設定します |  |
| /rtp | ランダムテレポート | 範囲 3200 ~ 32000、クーリング 10 分 |
| /sell | インベントリの物品を売却します | 売却可能な物品は「基本設定」を参照 |
| /sf | 粘液科技のメニューを開きます | ガイド・レシピ検索・研究進捗 |
| /sf guide | 粘液科技の新規者ガイドを開きます | 初参加時に自動で配布されます |
| /sfcalc calc <アイテム> [数量] | アイテムに必要な材料を計算します | /sfc calc <アイテム> [数量] でも可 |
| /sethome <家の名前> | 家を設定します | 最大 8 件まで |
| /shout <内容> | 全体へ叫びます | クールダウン 3 秒 |
| /spawn | 主都市へテレポートします |  |
| /status | サーバー状態を表示します |  |
| /tpa <プレイヤー> | プレイヤーへのテレポートを申請します | 申請は 60 秒で失効します |
| /tpahere <プレイヤー> | プレイヤーを自分のところへ呼びます |  |
| /worth | 手持ちのアイテムの販売価値を確認します |  |
| /worthlist | 売却可能なすべてのアイテムの価値を確認します |  |

::: tip ヒント
チャットで `[inv]`、`[ender]`、`[item]` を入力すると、インベントリ・エンダーチェスト・手持ちアイテムがそのまま表示されます。`@名前` でプレイヤーをメンションできます。
:::
