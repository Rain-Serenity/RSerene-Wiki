# コマンド一覧
| コマンド                                                   | 機能                                     | 備考                                                                                 |
|--------------------------------------------------------|----------------------------------------|------------------------------------------------------------------------------------|
| /back                                                  | 最後に保存した場所に戻る                           |                                                                                    |
| /balance                                               | 残高を確認する                                |                                                                                    |
| /baltop                                                | 残高ランキングを表示する                           |                                                                                    |
| /co i                                                  | ブロック記録照会モードをオン(オフ)にする                  |                                                                                    |
| /dback                                                 | 最後に死亡した場所に戻る                           |                                                                                    |
| /gmp mailbox                                           | メールボックスを開く；グローバルマーケットから取り下げたアイテムが保管される |                                                                                    |
| /gmp market gui                                        | グローバルマーケットを開く                          |                                                                                    |
| /gmp market help                                       | グローバルマーケットで利用可能なコマンドを表示する              |                                                                                    |
| /gmp market sell &lt;価格&gt; &lt;数量&gt;                 | 手に持っているアイテムを指定価格でグローバルマーケットに出品する       |                                                                                    |
| /money                                                 | 残高を確認する                                |                                                                                    |
| /msg                                                   | プレイヤーにプライベートメッセージを送信する                 |                                                                                    |
| /pay &lt;プレイヤー名&gt; &lt;金額&gt;                         | プレイヤーに送金する                             | 手数料3%                                                                              |
| /ping                                                  | レイテンシを確認する                             |                                                                                    |
| /playtime                                              | 合計プレイ時間を確認する                           |                                                                                    |
| /playtimetop                                           | サーバーのプレイ時間ランキングを表示する                   |                                                                                    |
| /removehome &lt;家の名前&gt;                               | 家を削除する                                 |                                                                                    |
| /res create &lt;領地名&gt;                                | 保護を作成する                                | 先に木のクワで2つの点を選択する必要がある                                                              |
| /res give &lt;領地名&gt; &lt;プレイヤー名&gt;                   | 保護をプレイヤーに譲渡する                          | /res confirmでの確認が必要                                                                |
| /res help                                              | 保護プラグインのヘルプを表示する                       |                                                                                    |
| /res pset &lt;プレイヤー名&gt; &lt;権限名&gt; true/false/remove | 保護の個人権限を設定する                           | 変更したい保護内で実行すれば保護名の指定は不要。/res set &lt;プレイヤー名&gt; のみを使用すると、この保護でのそのプレイヤーの権限設定GUIを開ける |
| /res remove &lt;領地名&gt;                                | 保護を削除する                                | /res confirmでの確認が必要                                                                |
| /res set &lt;権限名&gt; true/false/remove                 | 保護の全体権限を設定する                           | 変更したい保護内で実行すれば保護名の指定は不要。/res set のみを使用すると、保護の全体権限設定GUIを開ける                         |
| /rtp                                                   | ランダムテレポート                              | 範囲: 32000*32000                                                                    |
| /sell gui                                              | 売却メニューを開く                              | 売却可能なアイテムは「基本設定」を参照                                                                |
| /spawn                                                 | メインシティにテレポートする                         |                                                                                    |
| /tpa                                                   | 他のプレイヤーにテレポートをリクエストする                  |                                                                                    |
| /tpahere                                               | 他のプレイヤーに自分の場所へのテレポートをリクエストする           |                                                                                    |
| /tpsbar                                                | 自分のいるエリアのTPS、MSPTなどの表示バーを切り替える         |                                                                                    |
| /worth                                                 | 手に持っているアイテムの売却価格を確認する                  |                                                                                    |
| /worthlist                                             | すべての売却可能アイテムの価格を表示する                   |                                                                                    |
