# 基本設定
## サーバー基本構成
**このサーバーは [Lophine](https://GitHub.com/LophineLabs/Lophine) コアを使用しています。**  
**サーバーの機能については[サーバー設定ファイル](https://GitHub.com/Rain-Serenity/ServerConfig)をご確認ください。**  
::: warning 注意
サーバーに優しく接し、機械を密集させすぎないでください。/tpsbarを使用して自分のエリアの状態を確認しましょう！
:::
## 死亡時のアイテムロストなし
**死亡時のアイテムドロップを無効にしています。**

## 睡眠システム
**睡眠加速メカニズムとカスタム睡眠システムの両方を採用しており、[NoPhantomSleep](https://GitHub.com/Rain-Serenity/NoPhantomSleep) プラグインで実装されています。夜間にベッドを右クリックすると、一晩中寝たものとみなされ、周囲にファントムが出現しなくなります。** <br>
**30%のプレイヤーがベッドに入ると夜間加速が開始されます。**
## 視距離
**視距離は16チャンク、シミュレーション距離は12チャンクに設定されています。**

## 土地保護
**土地保護の作成ツールは木のクワに設定されています。最大保護範囲は512×256×512 (X×Y×Z)、高さ制限はありません（-64〜320まで可能）。**
**1ブロックあたり0.05ゲーム内通貨**
