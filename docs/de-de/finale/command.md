# Befehlsliste
::: tip Hinweis
Dieser Server läuft mit dem Original-Paket und ohne eigene Server-Befehle; die folgenden sind die im Spiel verfügbaren Vanilla-Befehle.
:::
| Befehl      | Funktion                                           | Anmerkung                    |
|-------------|----------------------------------------------------|------------------------------|
| /seed       | Den Seed der aktuellen Welt anzeigen               |                              |
| /spawnpoint | Den persönlichen Wiedereinstiegspunkt setzen       |                              |
| /locate     | Das nächste Biom oder die nächste Struktur finden  | Admin-Rechte erforderlich    |
| /trigger    | Ein vorkonfiguriertes Scoreboard-Ereignis auslösen | Von einem Admin eingerichtet |
