# Befehlsliste
::: tip Hinweis
Der CirnoArk-Server wird von Korvahet betrieben.
:::

| Befehl                                           | Funktion                                                                               | Hinweis                                                 |
|--------------------------------------------------|----------------------------------------------------------------------------------------|---------------------------------------------------------|
| /back                                            | Zurück zum zuletzt gespeicherten Ort                                                   |                                                         |
| /balance                                         | Deinen Kontostand anzeigen                                                             |                                                         |
| /baltop                                          | Kontostand-Rangliste anzeigen                                                          |                                                         |
| /co i                                            | Abfrage-Modus für Blockaufzeichnungen ein- oder ausschalten                            |                                                         |
| /dback                                           | Zurück zum Ort des letzten Todes                                                       |                                                         |
| /gmp mailbox                                     | Dein Postfach öffnen – hier landen alle Dinge, die du vom globalen Markt genommen hast |                                                         |
| /gmp market gui                                  | Den globalen Markt öffnen                                                              |                                                         |
| /gmp market help                                 | Die verfügbaren Befehle des globalen Marktes anzeigen                                  |                                                         |
| /gmp market sell &lt;preis&gt; &lt;anzahl&gt;    | Das Item in deiner Hand zu einem bestimmten Preis auf dem globalen Markt anbieten      |                                                         |
| /home                                            | Zu deinem Zuhause teleportieren                                                        |                                                         |
| /homes                                           | Alle deine Zuhause anzeigen                                                            |                                                         |
| /money                                           | Deinen Kontostand anzeigen                                                             |                                                         |
| /msg                                             | Einem Spieler eine private Nachricht senden                                            |                                                         |
| /pay &lt;spieler&gt; &lt;betrag&gt;              | Geld an einen Spieler überweisen                                                       | Gebühr 3 %                                              |
| /ping                                            | Deine Latenz anzeigen                                                                  |                                                         |
| /playtime                                        | Deine Spielzeit auf dem Server anzeigen                                                |                                                         |
| /playtimetop                                     | Rangliste der Spielzeit anzeigen                                                       |                                                         |
| /removehome &lt;name&gt;                         | Zuhause löschen                                                                        |                                                         |
| /res create &lt;name&gt;                         | Grundstück anlegen                                                                     | Zuerst mit der Holzhacke zwei Punkte auswählen          |
| /res info &lt;name&gt;                           | Informationen zum Grundstück anzeigen                                                  |                                                         |
| /res list                                        | Alle deine Grundstücke auflisten                                                       |                                                         |
| /res padd &lt;spieler&gt; &lt;recht&gt;          | Einem Spieler Rechte auf deinem Grundstück geben                                       | Nur Bauen, Abbau, Container und Benutzung               |
| /res remove &lt;name&gt;                         | Grundstück löschen                                                                     |                                                         |
| /res set &lt;recht&gt; true/false                | Globales Grundstücksrecht setzen                                                       | Im betreffenden Grundstück ausführen                    |
| /res sethome &lt;name&gt;                        | Teleportpunkt im Grundstück setzen                                                     |                                                         |
| /rtp                                             | Zufälliger Teleport                                                                    | 3200 ~ 32000 Blöcke, 10 Minuten Abklingzeit             |
| /sell gui                                        | Gegenstände im Inventar verkaufen                                                      | Verkaufbare Gegenstände siehe „Grundeinstellungen“      |
| /sf                                              | Slimefun-Menü öffnen                                                                   | Guide, Rezeptsuche und Forschungsfortschritt            |
| /sf guide                                        | Slimefun-Einstiegsguide öffnen                                                         | Du erhältst ihn automatisch beim ersten Beitritt        |
| /sfcalc calc &lt;gegenstand&gt; [&lt;anzahl&gt;] | Materialien für einen Gegenstand berechnen                                             | Kurzform: /sfc calc &lt;gegenstand&gt; [&lt;anzahl&gt;] |
| /sethome &lt;name&gt;                            | Zuhause setzen                                                                         | Bis zu 8 Zuhause                                        |
| /spawn                                           | In die Hauptstadt teleportieren                                                        |                                                         |
| /tpa &lt;spieler&gt;                             | Teleport zu einem Spieler anfragen                                                     | Die Anfrage läuft nach 60 Sekunden ab                   |
| /tpahere &lt;spieler&gt;                         | Einen Spieler zu dir herrufen                                                          |                                                         |
| /worth                                           | Verkaufswert des Gegenstands in der Hand prüfen                                        |                                                         |
| /worthlist                                       | Wert aller verkaufbaren Gegenstände nachschlagen                                       |                                                         |

::: tip Hinweis
Im Chat zeigen `[inv]`, `[ender]` und `[item]` direkt dein Inventar, deine Endertruhe und den Gegenstand in deiner Hand; mit `Spielername` erwähnst du einen Spieler.
:::
