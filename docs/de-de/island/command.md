# Befehlsliste

Der Skyblock-Server wird seit dem 29.07.2026 unabhängig vom Rain Serenity Server betrieben. Die folgenden Informationen stammen vom 29.07.2026 und werden nicht mehr aktualisiert.

| Befehl             | Funktion                                                        | Anmerkung |
|--------------------|-----------------------------------------------------------------|----|
| /rim tips          | Kleine Tipps anzeigen                                            |    |
| /rim recipemenu    | Die speziellen Crafting-Rezepte anzeigen                         |    |
| /rim slime         | Slime-Chunks anzeigen                                            |    |
| /tpsbar            | Die Anzeigeleiste für TPS, MSPT usw. deiner Region ein- (aus-)schalten |    |
| /plot auto         | Deine Insel erhalten                                             |    |
| /plot home         | Zu deiner Insel zurückkehren                                     |    |
| /plot setbiome     | Das Biom deiner Insel festlegen                                  |    |
| /plot sethome      | Den Teleportpunkt deiner Insel festlegen                         |    |
