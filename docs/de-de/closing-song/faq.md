## I. Anmeldung & Beitritt
### F1: Brauche ich einen Premium-Account?
A: Obwohl auf dem Server keine Premium-Authentifizierung aktiviert ist, benötigen Nicht-Premium-Nutzer einen <a href="https://littleskin.cn" target="_blank">LittleSkin</a>-Login, um dem Server beizutreten. Daher registrieren sich Nicht-Premium-Nutzer bitte zuerst bei <a href="https://littleskin.cn" target="_blank">LittleSkin</a> und melden sich in einem Drittanbieter-Launcher mit ihrem <a href="https://littleskin.cn" target="_blank">LittleSkin</a>-Konto an, bevor sie dem Server beitreten!

### F2: Wo lade ich das Paket herunter?
A: Aus den **Gruppendateien** der QQ-Gruppe 902620497; du kannst es auch von der [Release-Seite des ursprünglichen Autors](https://www.mcmod.cn/modpack/1133.html) selbst herunterladen.

### F3: Wie trete ich dem Server bei?
A: 1. Tritt der QQ-Gruppe 902620497 bei und lade das Paket „Closing Song“ aus den **Gruppendateien** oder von der [offiziellen Closing-Song-Seite](https://www.mcmod.cn/modpack/1133.html) herunter.<br>
1. Importiere das Paket direkt in PCL, HMCL oder einen anderen Launcher — installiere nichts neu und ändere keine Mods;<br>
2. Mehrspieler → Server hinzufügen, Adresse `CLSO.RSerene.com`;<br>
3. Beim ersten Beitreten kannst du einen Admin nach Startmaterial fragen; Details laut tatsächlichem Server-Status.

### F4: Warum komme ich nicht drauf / warum reconnectet es ständig?
A: Prüfe zuerst, ob du das richtige Paket nutzt und die Mods zum Paket passen; die Adresse ist `CLSO.RSerene.com`.

### F5: Kostet das Geld?
A: Nein, das Spielen ist kostenlos (Spenden sind völlig freiwillig, nie verpflichtend).

## II. Servermechanismen und Regeln
### F1: Wie viele Spieler hält der Server aus?
A: Etwa 15 Spieler gleichzeitig online. Bei vollem Server kommt man nicht rein — kurz warten oder in der Gruppe fragen.

### F2: Wird die Welt zurückgesetzt?
A: Nein. Vor einem Paketwechsel wird die alte Welt zuerst gesichert.

### F3: Wann wechselt das Paket?
A: Sobald dieses Paket durchgespielt ist; vor dem Wechsel gibt es in der Gruppe eine Abstimmung/Ankündigung.

### F4: Was tun bei Lag oder Disconnects?
A: Prüfe zuerst die Gruppen-Ankündigung auf Neustart-Zeiten; wenn viele gleichzeitig fliegen, ist es meist ein Server-Neustart oder eine Netzschwankung — kurz warten und wieder joinen.

### F5: Welche Regeln gelten auf dem Server?
A: Keine Hacks, X-Ray, Flug, Auto-AFK oder Skript-Item-Farmen; kein böswilliges PvP, keine Basen-Plünderung, keine Zerstörung fremder Builds, kein Spam, keine Beleidigungen; Vanilla-Redstone-Mechanismen und Mob-Farmen sind erlaubt, aber den Server absichtlich zu laggen oder Chunk-Loader zu missbrauchen ist verboten. Konkrete Bestimmungen laut Gruppen-Ankündigung.

## III. Urheberrecht und Community
### F1: Darf ich das Paket selbst verbreiten oder verkaufen?
A: Nein. Dieser Server erhebt von Spielern keinerlei Gebühren und verkauft oder verbreitet das Paket in keiner Form kostenpflichtig; es dient nur dem normalen Spiel der Spieler dieses Servers.

### F2: Wohin kann ich mich bei Problemen wenden?
A: Frage einen Online-Administrator im Spiel oder tritt der offiziellen QQ-Gruppe 902620497 bei und schreibe @Chosen_1st oder @Korvahet in der Gruppe.
