# 指令列表
::: tip 提示
完美算数工坊服务器由 Korvahet 运营。
:::

| 指令名称 | 功能 | 备注 |
|---|---|---|
| /back | 返回上一个保存的地点 |  |
| /balance | 查看你的余额 |  |
| /baltop | 查看余额排行榜 |  |
| /co i | 启动（关闭）方块记录查询模式 |  |
| /dback | 返回上一个死亡的地点 |  |
| /home | 传送到你的家 |  |
| /homes | 查看你的所有家 |  |
| /msg | 给某位玩家发送私聊 |  |
| /money | 查看你的余额 |  |
| /pay <玩家> <金额> | 给某位玩家转账 | 手续费 3% |
| /ping | 查看你的延迟 |  |
| /playtime | 查看你的在线时长 |  |
| /playtimetop | 查看服务器在线时长排行榜 |  |
| /removehome <家名称> | 删除家 |  |
| /res create <领地名> | 创建领地 | 需要先用木锄头选两个点 |
| /res info <领地名> | 查看领地信息 |  |
| /res list | 列出你的所有领地 |  |
| /res padd <玩家> <权限> | 给某位玩家添加领地权限 | 只能添加建造、破坏、容器、交互等权限 |
| /res remove <领地名> | 删除某个领地 |  |
| /res set <权限> true/false | 设置领地全局权限 | 在要调整的领地内执行 |
| /res sethome <领地名> | 设置领地内传送点 |  |
| /rtp | 随机传送 | 范围 3200 ~ 32000，冷却 10 分钟 |
| /sell | 出售背包中的物品 | 可出售的物品详见「基本设定」 |
| /sf | 打开粘液科技主菜单 | 包含指南、配方查询与研究进度 |
| /sf guide | 打开粘液科技新手指南 | 第一次进服会自动收到一份 |
| /sfcalc calc <物品> [数量] | 计算某个物品所需的材料 | 也可简写为 /sfc calc <物品> [数量] |
| /sethome <家名称> | 设置一个家 | 最多可设置 8 个 |
| /shout <内容> | 喊话，全服可见 | 冷却 3 秒 |
| /spawn | 传送到主城 |  |
| /status | 查看服务器状态 |  |
| /tpa <玩家> | 申请传送到其他玩家处 | 请求 60 秒内有效 |
| /tpahere <玩家> | 申请其他玩家传送到你这 |  |
| /worth | 查询手上物品的出售价值 |  |
| /worthlist | 查询所有可出售物品的价值 |  |

::: tip 提示
聊天时输入 `[inv]`、`[ender]`、`[item]` 可以直接展示背包、末影箱和手持物品；`@玩家名` 可以提及某位玩家。
:::
