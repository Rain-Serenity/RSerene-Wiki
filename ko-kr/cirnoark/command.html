일반 플레이어가 사용할 수 있는 명령어

아래 명령어는 모든 플레이어에게 열려 있어 바로 쓸 수 있습니다.

텔레포트와 위치

명령어설명
/back마지막으로 떠난 위치로 돌아가기
/dback마지막으로 죽은 위치로 돌아가기
/home자기 집으로 텔레포트
/homes자신의 모든 집 목록 보기
/sethome <이름>현재 위치에 집을 하나 설정(기본 이름은 Home)
/removehome <이름>집 하나 삭제
/spawn주도시 / 스폰 지점으로 돌아가기
/tpa <플레이어>상대를 텔레포트해 달라고 요청(요청은 60초 안에 유효, 3초 카운트다운)
/tpahere <플레이어>상대에게 나로 텔레포트해 달라고 요청
/tpaccept텔레포트 요청 수락
/tpdeny텔레포트 요청 거절
/rtp무작위 텔레포트(쿨타임 10분, 주세계 3200 ~ 32000블록 범위)

화폐와 상점

명령어설명
/balance내 잔액 보기
/money내 잔액 보기
/pay <플레이어> <금액>다른 플레이어에게 송금(수수료 3%)
/baltop부자 순위 보기
/sell가방의 아이템 판매(가격표로 환산)
/worth손에 든 아이템의 가치 조회
/worthlist전체 아이템 가격표 열기

채팅과 정보

명령어설명
/msg <플레이어> <내용>다른 플레이어에게 개인 메시지
/ping내 지연 시간 보기
/playtime내 접속 시간 보기
/playtimetop접속 시간 순위 보기
/shout <내용>외치기, 서버 전체에 표시(쿨타임 3초)

채팅 팁:

  • @플레이어명 —— 특정 플레이어를 멘션(쿨타임 30초).
  • @all —— 전체 멤버 부르기(쿨타임 5분, 추가 권한 필요).
  • [inv] —— 채팅에서 자기 가방을 보여주기.
  • [ender] —— 채팅에서 자기 에더 상자를 보여주기.
  • [item] —— 채팅에서 손에 든 물건을 보여주기.

슬라임 기술과 플레이

명령어설명
/sf슬라임 기술 메인 명령어. 가이드, 레시피 조회, 연구 진행도 등의 하위 명령어를 포함
/sf guide초보 가이드 열기(첫 입장 시 자동으로 한 부가 지급됩니다)
/sfcalc calc <아이템> [수량]레시피 계산기: 어떤 아이템(또는 N개)을 만드는 데 필요한 재료 계산
/sfcalc calc <아이템> [수량]약칭 /sfc calc <아이템> [수량]으로도 사용 가능

팁

/sfcalc는 레시피만 조회하고 재료를 소모하지 않으니, 산업 라인을 준비할 때 가장 편한 방법입니다.

명령어설명권한 노드

/nps remove <플레이어>플레이어를 명단에서 제거관리자

현재 열려 있지 않은 명령어

아래 명령어는 서버에 존재하지만 플레이어는 쓸 수 없습니다. 다른 사람이 쓰는 걸 봐도 이상하게 생각하지 마세요:

명령어설명
/tp즉시 텔레포트, 플레이어에게는 열려 있지 않음(/tpa를 사용하세요)
/warp, /setwarp워프 시스템, 현재 워프가 하나도 없고 열려 있지 않음
/kit키트 시스템, 현재 설정된 키트가 없음
/heal, /feed회복과 포만감, 열려 있지 않음
/fly, /effect, /enchant, /give, /gamerule창작·치트 계열 명령어, 열려 있지 않음
/nick닉네임 변경, 열려 있지 않음
/rankup랭크 시스템, 현재 꺼져 있음
/tpaccept, /tpdeny권한은 부여되어 있지만 별칭은 아직 꺼진 상태. /tpa의 버튼으로 직접 수락하거나 거절하세요

권한 설명

  • 권한은 LuckPerms에서 일괄 관리하며, 현재 서버에는 default 그룹 하나만 있고 그 안에 cmi.command.* 명령어 권한 30개와 청크 조회(coreprotect.inspect), 서버 상태 조회가 들어 있습니다.
  • /residence.group.Default와 /residence.group.Event는 서로 다른 두 가지 영토 할당량에 대응합니다: 기본 그룹 8개, 이벤트 그룹 12개.
  • 영토 안의 플래그(건설, 파괴, 상자 개봉, PVP, 폭발 가능 여부 등)는 영토 주인이 직접 설정하며, 명령어 권한과는 별개의 독립적인 시스템입니다.
  • 밴되었거나 채팅이 금지된 상태에서는 관리 계열 명령어를 쓸 수 없습니다.

자주 묻는 질문 요약

  • 명령어가 먹통인데? 먼저 철자를 확인하세요. /tpa는 상대가 온라인이어야 하고, 요청은 60초 안에 유효합니다.
  • 어떤 아이템을 받지 못하거나 쓸 수 없는데? 일부 아이템은 영토 플래그로 보호됩니다(컨테이너, 파괴, 상호작용). 영토 주인이 권한을 줘야 합니다.
  • 어떤 물건을 어떻게 만드는지 보고 싶다면? /sfcalc calc <아이템>을 쓰세요. 레시피를 하나씩 뒤지는 것보다 훨씬 빠릅니다.
